## 数据源评估方法论

在评估每个数据源时，使用以下维度：
- **覆盖重叠**：是否已由另一个来源完全替代？
- **独特性**：是否提供了任何其他来源都无法提供的数据/指标？
- **成本**：是免费（开源爬虫）还是付费（订阅/API）？付费层级有多少？
- **集成状态**：是否已在生产环境中运行？迁移工作量是多少？
- **对策略的影响**：是否有策略指标直接依赖于该来源？（若"是"，则该来源不可触碰）

## 最终裁决

### 保留（5个来源）

| 来源 | 不可替代性 |
|------|--------------|
| **Tushare MCP** | 130+接口；覆盖日常量化数据需求的90% |
| **Coze/恒生聚源** | 5类独家数据——机构一致预期、舆情穿透、招投标、ETF申赎、产业链 |
| **SQLite + Parquet** | 已验证的存储方案；18张表；沉淀了数月数据资产 |
| **CuaDriver + 同花顺免费版** | GS信号、主力雷达、暗盘资金——同花顺独有，无法通过API获取 |

### 砍掉（4个来源）

| 来源 | 替代方案 | 影响 |
|------|----------|------|
| **akshare** | → Tushare `daily` + `stk_factor_pro` | 退役爬虫；获得130+技术因子 |
| **腾讯API** | → Tushare `bak_daily` 内部备用 | 移除冗余备用层 |
| **东方财富直连** | → Tushare `moneyflow_dc` | 已在Tushare内可用 |
| **Coze独立日报** | → Hermes统一日报 | Coze方面实际生成量为零 |

### 关于L2数据源的说明

**同花顺LV2 和 通达信L2 均非当前活跃订阅。** 截图流程使用同花顺免费版。GS信号（同花顺专有黑盒指标）是截图流程未被API替代的原因。
