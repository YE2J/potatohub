# ETF 网格交易（Grid Trading）

把《网格交易法》（徐华康）的可操作流程落地：从定资金到破网处置的六步方法、
参数规则表、止损纪律与实证回测结论。适用 A 股 ETF（宽基/行业/主题），个股需
叠加基准指数控仓。

## 触发场景

- 用户给出一只/多只 ETF + 资金量，要「设计网格方案 / 画网格表」
- 用户要评估网格参数（区间/格距/每格金额/标的数据）是否合理
- 用户问网格要不要止损、跌破/涨破区间怎么办、网格是否适合某标的

## 核心公式（速算）

| 项目 | 公式 | 说明 |
|---|---|---|
| 每格利润 | (卖价−买价)×每格股数 | 无跳空每笔恒定 |
| 格数 | 区间幅度 ÷ 格距 | 例 20%÷1%=20 格 |
| 单格金额 | 总资金 ÷ 格数 | 固定仓位法每次同股数取整百 |
| 日波动率 | 年σ ÷ √256 ≈ 年σ÷16 | 定格距使 1~3 天可触发一次 |
| 总收益 | 持仓损益 + 网格损益 | 网格损益=卖出次数×单笔 |
| 完成一次网格 | = 卖出一次（买→卖） | 记录卖出次数即可估网格获利 |

## 六步落地流程

1. **定资金与标的数**：可用资金；新手 2 档起（2~20 档）；钱少先算手续费
   （每格利润须远大于佣金，否则白做）。
2. **选标的**：高波动 + 长期向上 + 相对低档/上升趋势；历史波动率参考
   （年σ÷16≈日σ）；错了一定按计划止损换标的（选对与否不是重点）。
3. **设定网格**：
   - 区间：新手先试未来 1 个月~半月可能区间；宽→资金效率差，窄→涨破卖光/跌穿没钱接；
   - 格距/格数：0.5%~3% / 格、6~25 格（常 15）；跨度小用固定金额格，跨度大用固定百分比格；
   - Excel 网格表：每格触发价、每格股数（固定仓位法=单格金额÷触发价取整百）、
     资金占用累计；按现价对照表建基本底仓（程序化注意基准价=最接近档位，设错会瞬间满仓）。
4. **执行**：手动前晚挂好各档买/卖单，成交后补相邻档（卖出一格→补低一档买价，反之亦然）；
   自动化次日盘中确认成交，防设定错误变成灾难。
5. **记录**：只记各档当日卖出次数（=完成网格次数），横比多标的网格效率，及时换更优标的。
6. **破网处置**：涨破上限=止盈出场（赚得比持有少但赢），换标再进；跌破下限按优先级：
   止盈换标 → **止损换标的（默认）** → 转定投（勿急打光子弹） → 卖部分重建低网格（复杂）
   → 等待反弹（**最差，禁躺平**）。

## 标准网格模板（实战/回测默认，第七章+第八章）

| 参数 | 值 |
|---|---|
| 区间 | 入场价×124%（上限）/ ×94%（下限）＝上下 30% |
| 格距 | 2% |
| 格数 | 15 格 |
| 进场位 | 第 12 格（上方留 12 格=24%，下方 3 格=6%） |
| 建仓资金 | ~80%（余 20% 承接下 3 格） |
| 每格股数 | (资金÷15) ÷ 入场价，取整百 |

## 止损/止盈/择时纪律（第七章）

- 出场信号 **二选一，勿混用**：①收盘跌破「过去 4 日最低点」；②MACD DIF 下穿零轴。
- 也可用「进场后自高点回落 2% 出场」（第八章回测最优：总收益 34.8%、最大回撤 4.7%、夏普 1.08）。
- 牛熊控仓：上证指数日线 DIF>0 → 80%+ 仓位、最多同时 3 只；DIF<0 → ≤30% 仓位。
- 波段中再进场：DIF>0 波段内，收阳且收盘过最近阴线高点时进场，止损仍用 4 日低点。

## 回测实证结论（510300，2015.1–2021.9，1分钟K，第八章）

1. 格距越小越好（不计成本）：0.25% > 0.5% > 1% > 2%；
2. 超额收益 ∝ 区间内波动次数——区间设得越准越好、标的波动越大越好；
3. 收益由终点相对起点位置定方向 → 网格是强路径依赖策略，方向不对网格利润盖不住持仓亏损；
4. 单纯网格跑不赢长期持有（33.65% 基准）；**加止损/止盈后总收益相当但回撤大幅下降**，
   可加 2 倍杠杆（回撤 9.4%、收益 69.7%）；
5. 组合版（10 ETF 池 + DIF 择时 + 标准模板）：3 年 59.70%、夏普 2.12、回撤 8.72%。

## 易错点/检查清单

- [ ] 改「每格金额」≠ 小调整：= 偷改格数（5万/15格 3500→1750 元 = 实际 30 格）
- [ ] 资金不够时每格最小 100 股都买不起 → 缩区间/换低价标的
- [ ] 跌破下限「等待反弹」是多数人本能 = 最差选择
- [ ] 被套回本后「全部清仓」会错过主升段（第六章教训：应转网格低买高卖逐步了结）
- [ ] 个股/大股票池必须用基准指数控仓（熊市也会满仓→连环止损）
- [ ] 手动格距太密 → 盘中补单忙不过来；自动化次日必须盘中核成交
- [ ] 出场法混用（4日低点 vs DIF 零轴）→ 每次都在后悔切换，选一种执行到底

## 相关概念速记

- **卖认沽 ≈ 天然网格**：卖 1 张行权价 P 认沽（1 万股）≈ P 元满仓网格；权利金 ≈ 市场定价的
  月度网格预期收益；控制杠杆则风险相当（反向检验：网上「网格无风险/双向开网格」用
  卖沽+卖购一对照即知有风险）。
- **雪球 = 带敲出条款的网格**：敲出早则无法复利、「年化」是表面数字；网格可自复制且更灵活。
- **定投+网格**：跌破下限转定投降成本，涨回区间网格重启；切勿急跌中打光子弹。

## 验证（收尾必做）

- 方案可执行性：网格表价位/股数/资金占用能逐行对上（Σ每格金额≈总资金）
- 用「每格利润−双边手续费>0」检查格距下限；
- 若用户要求回测 → 走 a-share-quant-backtest 流程，先验证「波动次数/格距/成本」三敏感性。
