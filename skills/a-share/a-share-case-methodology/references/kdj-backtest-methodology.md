# KDJ_J<0 单因子回测方法论

## 背景

从 20 只 AI 大牛股的跨案例分析中发现：
- KDJ_J < 0 在买入前的触发率 = 95%（20只中19只触发）
- 平均提前 10.5 天触发（中位数 9 天）
- 卖出日 KDJ_J > 100 或 RSI > 80 的准确率 100%

## 回测设计

策略规则：
- **买入**：KDJ_J < 0（J值进入超卖区）→ 次日开盘买入
- **卖出**：KDJ_J > 100 OR RSI(14) > 80 OR -8%止损
- **仓位**：每只1/3资金，最多3只，按J值超卖程度(-kdj_j)排序选股
- **资金**：初始100万
- **手续费**：0.03%佣金 + 0.1%印花税（卖出时），最低5元
- **冷静期**：卖出后5天不买入同一只

## 核心教训

### 1. KDJ_J<0 是反转信号，非趋势信号
- 在单边下跌市中会反复被套（2025年2~4月）
- 每次买入后被-8%止损打掉，本金快速消耗
- **必须加市场环境过滤**：大盘MA20以上才开仓，可避免大部分假信号

### 2. 精选池 vs 全市场池
- 在20只已知赢家上：+100%（但买入持有+380%）
- 在99只自选股上：+50.6%
- 说明策略有效，但回测标准不能选「已知赢家」池（幸存者偏差）
- **正确的回测方式**：全市场+行业中性选股，不能只测白名单

### 3. 灾难回撤的根源
- 2025年2月~3月市场持续下跌 → KDJ_J<0反复触发 → -8%止损反复消耗本金
- 到4月关税暴跌（4月7日一天跌20%）时只剩¥1,195
- **等权重仓位模型在回撤时不会减仓**，这是致命缺陷
- 需改进：动态仓位（净值回撤>20%时减半仓位）

### 4. 超跌反弹的捕获能力
- 从¥568回到¥200万证明了KDJ_J<0在真正的底部反转时有效
- 关键反转月份：2025年6月（PCB/光模块反转）
- 但问题在于：能否活到反转那天

## 改进方向

### 方向A：趋势过滤
```
if 大盘MA20 向上:
   开启KDJ_J<0买入
else:
   空仓等待
```
预期：减少70%的假信号，最大回撤控制在-30%以内

### 方向B：自适应止损
- 布林带下轨附近买入 → 止损设在布林带下轨下方3%
- 盈利>10%后改用移动止损（从最高点回撤5%）
- 避免窄幅震荡中的频繁假止损

### 方向C：减少开仓频率
- 增加条件：KDJ_J<0 + KDJ_K上拐（即J从最低点回升）
- 不是所有J<0都买入，而是等超卖确认信号出现

### 方向D：融合GS+主力雷达
```
买入 = KDJ_J<0 AND GS在G区间 AND 主力线上穿零轴
卖出 = KDJ_J>100 OR 主力线连降3天
```
预期：用GS/主力雷达过滤掉没有主力资金配合的超卖

## Pitfalls

- **位置定价**：策略使用开盘价，实际交易中会滑点，回测低估损失约0.5-1%
- **跌停日**：-8%止损在跌停日可能无法执行，股价可能连续跌停（如2025-04-07~09），应使用 `min(close, 跌停价)` 模拟
- **复权处理**：`daily_kline` 表是前复权还是后复权？如果用了前复权，历史低价可能被调成负数，导致KDJ计算出错。需确认数据源。
- **回测幸存者偏差**：99只自选股也是当前没退市的，测试中漏掉了已经退市/ST的股票。真正严谨的回测要用 **全市场历史成分股列表**。
