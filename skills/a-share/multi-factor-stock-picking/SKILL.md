# Multi-Factor Stock Picking — 多因子选股模型构建

把已验证的单个因子**组合成完整选股模型**的方法论：过滤规则 → 因子集 → 交集/加权选择 → 组合输出。**基于托托里罗《量化投资策略》(ch11-13) + Finding Alphas (ch5) 交叉互补**，直接服务于用户因子工厂的 Top10 输出层。

## When to Use

- 用户要把因子库中的已验证因子组合成选股模型
- 用户要构建/优化 Top10 选股输出
- 用户要添加选股过滤规则（市值/价格/估值约束）
- 用户要决定因子间用交集还是加权

## 步骤 1 — 选股池过滤（先过滤再打分）

**过滤规则（参考托托里罗 ch13）**：
| 规则 | 理由 |
|---|---|
| 市值 > 阈值（美股5亿$，A股建议按分位） | 避免小盘不必要波动 |
| 价格 > 阈值（如2元） | 低价股陷阱 |
| EBIT/投入资本 ≥ 35% | 排除盈利质量差 |
| EV > 0、P/E > 0 | 防负值导致 ROE/EV-EBITDA 失真 |
| 排除 ST/退市风险 | 存活者偏差处理 |

> 过滤在前、打分在后——避免极端值污染因子分布。

## 步骤 2 — 因子集选择（已验证因子）

**7 大因子类别**（托托里罗全书框架，每类选代表因子）：

| 类别 | 代表因子 | 计算 |
|---|---|---|
| 盈利性 | EBIT/投入资本、ROE、现金ROIC | EBIT/(股东权益+长期债务+优先股+少数股东权益) |
| 估值 | P/E(TTM)、P/S、EV/EBITDA | 市值/EPS、市值/销售额、EV/EBITDA |
| 现金流 | FCF/价格、经营现金流/股东权益 | 12月经营现金流-资本支出 |
| 成长性 | EPS增长、收入增长 | 两年平均EPS增长 |
| 资产配置 | 股息收益率、回购、债务削减 | "股东友好"信号 |
| 价格动量 | 12个月价格变化、相对强弱 | 供求平衡 |
| 危险信号 | 负ROE/负现金流等 | 排除/卖空候选 |

**选因子纪律**：
- 每个类别 1-2 个即可，**类别不宜过多**（输入数据类别限制）
- 优先选已在 factor_ic 验证中 IC/ICIR 达标的因子
- 检查因子间相关性：**双因子独立性测试**（相关因子叠加不增超额收益只增复杂度）

## 步骤 3 — 组合方式选择（交集 vs 加权）

| 方式 | 适用 | 优点 | 缺点 |
|---|---|---|---|
| **交集**（全部因子排名前N%） | 因子数少(≤8)、高置信 | 质量最纯、夏普高 | 可能选不出股票 |
| **加权打分**（因子标准化后加权求和） | 因子数多、需覆盖 | 稳定、可调权重 | 极端值需处理 |
| **分位交集 + 权重混合** | 综合 | 兼顾 | 复杂 |

**托托里罗交集法实证**（高盈利+正现金流+低估值简单组合）：夏普 0.97、最大损失 2.5%。
**Finding Alphas 迭代链**（加权+中性化）：行业中性化(IR 1.37) → rank化(1.76) → decay(1.82)。

## 步骤 4 — 因子处理（组合前必做）

1. **标准化/rank化**：因子转排名（0-1）或 z-score，消除量纲
2. **去极值**：clamp 或 winsorize，防止异常值主导
3. **中性化**（可选）：行业/市值中性化（Sum(alpha, same_industry)=0），牺牲收益换稳健
4. **decay 平滑**（可选）：信号多日平均降换手（3日decay 换手 63%→42%）

## 步骤 5 — 输出与评估

**输出**：Top N 股票列表 + 每只得分分解（哪些因子贡献）
**评估**（组合后必测）：
- [ ] 组合 IC/ICIR（截面预测力）
- [ ] 五分位单调性（Q1→Q5 单调 = 稳健）
- [ ] 换手率 tvr（>30% 必做成本敏感性）
- [ ] 与沪深300 对比的超额收益
- [ ] 最大回撤/回撤时长
- [ ] 样本外验证（walk-forward）

## 验证 checklist（模型交付标准）

- [ ] 过滤规则明确（市值/价格/估值约束）
- [ ] 因子集每类 1-2 个且相关性 <0.7
- [ ] 组合方式选定（交集/加权/混合）并说明理由
- [ ] 因子已标准化/去极值
- [ ] 组合后五分化单调 + 成本敏感性通过
- [ ] 样本外验证通过

## Pitfalls

- **过滤放打分后** = 极端值污染因子分布，先过滤
- **相关因子叠加**不增超额收益只增复杂度（双因子测试先查相关性）
- **交集法可能选不出股票**：因子过多时降为 Top20% 交集或改加权
- **市值因子在 A 股 2017 后失效**：历史有效性需样本外重新验证
- **不要为组合而组合**：每个因子都必须先单独验证过（组件因子原则）
