# Multi-Factor Stock Picking — 多因子选股模型构建

把已验证的单个因子**组合成完整选股模型**的方法论：过滤规则 → 因子集 → 交集/加权选择 → 组合输出。**基于托托里罗《量化投资策略》(ch11-13) + Finding Alphas (ch5) 交叉互补**，直接服务于用户因子工厂的 Top10 输出层。

## When to Use

- 用户要把因子库中的已验证因子组合成选股模型
- 用户要构建/优化 Top10 选股输出
- 用户要添加选股过滤规则（市值/价格/估值约束）
- 用户要决定因子间用交集还是加权

## 步骤 1 — 选股池过滤（先过滤再打分）

**过滤规则（参考托托里罗 ch13）**：
| 规则 | 理由 |
|---|---|
| 市值 > 阈值（美股5亿$，A股建议按分位） | 避免小盘不必要波动 |
| 价格 > 阈值（如2元） | 低价股陷阱 |
| EBIT/投入资本 ≥ 35% | 排除盈利质量差 |
| EV > 0、P/E > 0 | 防负值导致 ROE/EV-EBITDA 失真 |
| 排除 ST/退市风险 | 存活者偏差处理 |

> 过滤在前、打分在后——避免极端值污染因子分布。

## 步骤 2 — 因子集选择（已验证因子）

**7 大因子类别**（托托里罗全书框架，每类选代表因子）：

| 类别 | 代表因子 | 计算 |
|---|---|---|
| 盈利性 | EBIT/投入资本、ROE、现金ROIC | EBIT/(股东权益+长期债务+优先股+少数股东权益) |
| 估值 | P/E(TTM)、P/S、EV/EBITDA | 市值/EPS、市值/销售额、EV/EBITDA |
| 现金流 | FCF/价格、经营现金流/股东权益 | 12月经营现金流-资本支出 |
| 成长性 | EPS增长、收入增长 | 两年平均EPS增长 |
| 资产配置 | 股息收益率、回购、债务削减 | "股东友好"信号 |
| 价格动量 | 12个月价格变化、相对强弱 | 供求平衡 |
| 危险信号 | 负ROE/负现金流等 | 排除/卖空候选 |

**选因子纪律**：
- 每个类别 1-2 个即可，**类别不宜过多**（输入数据类别限制）
- 优先选已在 factor_ic 验证中 IC/ICIR 达标的因子
- 检查因子间相关性：**双因子独立性测试**（相关因子叠加不增超额收益只增复杂度）

## 步骤 3 — 组合方式选择（交集 vs 加权）

| 方式 | 适用 | 优点 | 缺点 |
|---|---|---|---|
| **交集**（全部因子排名前N%） | 因子数少(≤8)、高置信 | 质量最纯、夏普高 | 可能选不出股票 |
| **加权打分**（因子标准化后加权求和） | 因子数多、需覆盖 | 稳定、可调权重 | 极端值需处理 |
| **分位交集 + 权重混合** | 综合 | 兼顾 | 复杂 |

**托托里罗交集法实证**（高盈利+正现金流+低估值简单组合）：夏普 0.97、最大损失 2.5%。
**Finding Alphas 迭代链**（加权+中性化）：行业中性化(IR 1.37) → rank化(1.76) → decay(1.82)。

## 步骤 3b —（可选）Fermi-Dirac 熵定权：EFM 稳健复制定权（论文 2609.03552）

出处：Arratia & Gzyl (2026), "An Entropic Factor Model for Robust Portfolio Replication", arXiv:2609.03552。
一句话：把"给 N 个资产定权、去复制 K 个目标因子/基准"建模成**盒约束下的熵正则逆问题**，两阶段统一求解——
阶段 1 熵估计因子载荷 β（抗噪声极端值），阶段 2 用同一熵原则解复制权重（天然惩罚过度杠杆与极端集中）。
与步骤 3 的"交集/加权打分"是不同维度的定权法：那是截面打分排序，这是**贴目标暴露的最优权重建模**。

### 何时用本步
- 指数/ETF **部分复制**：沪深300/中证500 等用前 50–100 只权重成分股篮子去复制指数收益（替代买全成分）；
- TopN 组合"贴基准定权"：步骤 1–3 选出股票后，用本步把权重解成"市场 β≈目标、Σw=1、低换手"的组合；
- 因子多空/FMP 复制：把不可交易因子（宏观、风格）映射成可交易篮子。
- 不适用的场景：纯 alpha 最大化/截面打分排序（那是步骤 3/5 的活，本步是复制器，不是 alpha 放大器）。

### 数学核心（论文 §3 + §4；⚠️ 落地前必读原文核对符号，见文末清单）
统一问题：Aξ = y，ξ ∈ 𝒦 = Π_j[a_j,b_j]（盒约束），A 欠定/病态 → 无穷解。
选择准则（论文 Eq.2–3）：**最小化 Ψ(ξ) = Σ_j [p_j·ln p_j + (1−p_j)·ln(1−p_j)]，p_j=(ξ_j−a_j)/(b_j−a_j)**
（即负的 Fermi-Dirac 熵，天然对数障碍：ξ_j 逼近盒边界时边际代价 → ∞），约束 Aξ=y。
- 对偶（Eq.4–8）：Φ(τ) = Σ_j ln(e^{a_j τ_j}+e^{b_j τ_j})；Ψ 与 Φ 互为凸共轭，梯度互为反函数。
- **解是闭式的**（Eq.13，logistic/softmax 端点插值）：
  ξ_j* = [a_j·e^{a_j θ_j} + b_j·e^{b_j θ_j}] / [e^{a_j θ_j} + e^{b_j θ_j}]，θ = Aᵀλ*
- λ* = argmax_λ [⟨λ,y⟩ − Φ(Aᵀλ)]（无约束严格凸对偶，Newton/L-BFGS 秒级；⚠️ 论文 KKT 写 ∇Ψ−Aᵀλ*=0，
  对偶取 max，与常见"min 对偶"惯例符号相反，落地必须按原文 Σ(λ,y)=⟨λ,y⟩−Φ(Aᵀλ) 最大化核对梯度）。

**阶段 1 — 熵回归估载荷**（论文 §4.1，逐资产并行）：
每资产 i 独立求解 Aξ=X_i：ξ=[β₀,i; β_i,1..K; ε_i(1..T)]∈ℝ^{1+K+T}，A=[1 F I_T]（F 为 T×K 因子收益），
盒约束取**数据驱动经验界**：β 界用相邻日收益差分比值 inf/sup（Eq.23–24），
噪声包络 E_i = max(1.05·r_i^max, 0.5·σ(X_i))（Eq.25–27，r_i^max 为中点模型残差极值，5% 缓冲+σ 下限防低波时过紧）。
作用：极端单日噪声被包络吸收，载荷不被单个 outlier 拖走（论文称 Fermi-Dirac 项为"对数障碍"）。

**阶段 2 — 熵定复制权重**（论文 §4.2）：A=[Bᵀ; 1ᵀ]∈ℝ^{(K+1)×N}，y=[p; 1]（p=目标因子暴露，如市场 β=1），
盒约束默认 𝒦=[0,1]^N（long-only 无杠杆）；**建议软边距 w_i∈[−0.05, 0.999]**（论文 Remark 1）——
严格 0 下界在市场冲击时会逼出"corner solution"边界抖动、人为放大换手。
若 Bᵀw*=p 精确可解则复制误差只剩 E[⟨w,ε⟩²]（残差项）；权重解自动分散（最大熵原则：满足约束的最分散分配）。
```python
# 阶段 2 迷你实现（✓小型随机面板自测：Σw=1、Bᵀw=p 精确满足、w∈[0,1] 且摊开）
from scipy.optimize import minimize
import numpy as np
def fd_weights(B, p, a=0.0, b=1.0):      # B: (N资产,K因子) 载荷矩阵；p: K 维目标暴露
    N, K = B.shape
    A = np.vstack([B.T, np.ones((1, N))]); y = np.concatenate([p, [1.0]])   # 预算 Σw=1
    def th(lm): return A.T @ lm
    def f(lm):                            # 对偶：min [Φ(Aᵀλ) − λᵀy]
        t = th(lm); return np.sum(np.log(np.exp(a*t)+np.exp(b*t))) - lm @ y
    def g(lm):
        t = th(lm); ea = np.exp(a*t); eb = np.exp(b*t)
        return A @ ((a*ea+b*eb)/(ea+eb)) - y
    res = minimize(f, np.zeros(K+1), jac=g, method='L-BFGS-B')
    t = th(res.x); ea = np.exp(a*t); eb = np.exp(b*t)
    return (a*ea + b*eb)/(ea+eb)          # ξ_j*：端点 logistic 插值
```
⚠️ 数值：θ 大时 e^{aθ}+e^{bθ} 溢出——a,b 有限时用 log-sum-exp 或直接写 logistic 形式
（a=0,b=1 时 ξ* = σ(θ)，σ 为 sigmoid；一般区间 = a+(b−a)·σ((b−a)θ) 同式）。

### 论文报告的效果（诚实引用，含代价）
- Exp.1 标普500/20 股复制（2021–2023 样本外）：EFM 跟踪误差 7.22% vs OLS 6.79%（**让了 43bp 精度**），
  但偏差 1.08% vs 1.36%、波动 14.50% vs 15.13%、回撤 17.53% vs 19.24% 更好——OLS 靠给训练期高 β 股过拟合降方差。
- Exp.3 单资产闪崩（AMZN −25% 单日，因子不动）：OLS 把 β 拉到 1.22、仍配 5.73%；EFM β→−1.26、权重砍到 **0.27%**
  （≈1/20，论文称概率式"熔断"）；净收益 17.01% vs 15.54%。
- Exp.4 部分复制+摩擦（10bp 成本，2019–2023）：换手 135.24% vs 139.51%；Exp.5 COVID 期：换手 **266.93% vs 418.51%**，
  净收益 27.85% vs 25.64%、回撤 30.04% vs 31.27%——高波动期熵正则主要赢在换手/集中度，而非跟踪精度。
- 结论模式：EFM 拿少量跟踪误差换换手与集中度；成本敏感性场景（A股双边佣金+冲击+涨跌停滑点）里净收益通常占优。

### A股落地（探索性，⚠️ 需先细读原文）
1. **指数/ETF 部分复制**：tushare `index_weight`（成分与权重）+ `daily`（前复权收益）。
   目标因子取指数日收益（K=1，p=[1] 市场 β），或取多因子暴露向量。篮子 = 指数前 50–100 权重股（流动性门槛），
   全成分复制时 Bᵀw=p 可能不可行（N 大且盒窄），先验"可复制性"（解对偶可行性）。
2. **TopN 贴基准定权**：步骤 1–3 选出的候选做阶段 2，p 里同时写市场 β 与想要的风格/行业暴露；
   月度调仓，用 soft-margin 盒；把换手直接当成本项评估（参照 skill 步骤 5 的 tvr 检查）。
3. **因子多空/FMP 定权**：目标因子不可交易（如价值/质量）→ 载荷矩阵用阶段 1 熵回归估，p 取单位因子暴露。
4. 数据卫生：A股涨跌停一字板/停牌日收益率须剔除（差商界 L/U 遇 0 分母会爆），与 a-share-data 管线对齐。

### ⚠️ 落地前细读清单（本模块为可选探索项，未实跑 A股全流程）
1. 目标函数精确形式：论文是 **min Ψ（负 Fermi-Dirac 熵）s.t. Aξ=y**，Ψ 凸、边界发散（对数障碍）；
   文中"maximum entropy"提法指解在盒内**最分散**，勿理解成最大化 Ψ。
2. 对偶符号/KKT：λ 的维数 = 约束行数（阶段1 每资产 T 行、阶段2 共 K+1 行）；Σ(λ,y)=⟨λ,y⟩−Φ(Aᵀλ) 取 **max**。
3. 阶段 1 是 N 个独立小问题（逐资产），阶段 2 是单一大问题——别把载荷矩阵拼成一个大 A 一次解。
4. 论文实验仅 20 只美股/复制 SPY 级别验证，无 A股/大 N 证据；成分数大时对偶维数低（K+1）仍是优势，
   但阶段 1 的差分比值 β 界对噪声敏感，A股样本内先做 β 界敏感性。
5. 明确目标定位：EFM 产出的是"贴暴露的稳健复制权重"，若直接拿它当 Top10 等权替代品，等于要求
   Top10 恰好能复制目标指数——不可行时对偶无解/退化解，需回落打分加权（步骤 3）。

## 步骤 4 — 因子处理（组合前必做）

1. **标准化/rank化**：因子转排名（0-1）或 z-score，消除量纲
2. **去极值**：clamp 或 winsorize，防止异常值主导
3. **中性化**（可选）：行业/市值中性化（Sum(alpha, same_industry)=0），牺牲收益换稳健
4. **decay 平滑**（可选）：信号多日平均降换手（3日decay 换手 63%→42%）

## 步骤 5 — 输出与评估

**输出**：Top N 股票列表 + 每只得分分解（哪些因子贡献）
**评估**（组合后必测）：
- [ ] 组合 IC/ICIR（截面预测力）
- [ ] 五分位单调性（Q1→Q5 单调 = 稳健）
- [ ] 换手率 tvr（>30% 必做成本敏感性）
- [ ] 与沪深300 对比的超额收益
- [ ] 最大回撤/回撤时长
- [ ] 样本外验证（walk-forward）

## 验证 checklist（模型交付标准）

- [ ] 过滤规则明确（市值/价格/估值约束）
- [ ] 因子集每类 1-2 个且相关性 <0.7
- [ ] 组合方式选定（交集/加权/混合）并说明理由
- [ ] 因子已标准化/去极值
- [ ] 组合后五分化单调 + 成本敏感性通过
- [ ] 样本外验证通过

## Pitfalls

- **过滤放打分后** = 极端值污染因子分布，先过滤
- **相关因子叠加**不增超额收益只增复杂度（双因子测试先查相关性）
- **交集法可能选不出股票**：因子过多时降为 Top20% 交集或改加权
- **市值因子在 A 股 2017 后失效**：历史有效性需样本外重新验证
- **不要为组合而组合**：每个因子都必须先单独验证过（组件因子原则）
