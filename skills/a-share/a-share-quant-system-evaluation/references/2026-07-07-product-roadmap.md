# 量化系统产品经理评估报告 (2026-07-07)

> 评估对象: A股个人量化系统产品路线
> 评估日期: 2026-07-07

## 用户画像

- 个人A股投资者，短线偏波段（3只×1/3仓位）
- 技术路线: 纯pandas/numpy自实现，拒绝重框架
- 已有「薯仔交易系统」(同花顺L2) 作为交易执行器
- 核心矛盾: 数据层和因子层投入大量精力，但决策输出层是空的

## MVP定义

**MVP = 能跑赢指数的信号输出系统，而非数据丰度更高的仪表盘**

### 做什么
1. 修复买入信号IC方向（当前IC为负 → 正）
2. 每日选股信号输出（晨报含选股候选池）
3. 自选股当日操作建议（持有/加仓/减仓/观望）

### 不做什么
- ⛔ 不新增数据源
- ⛔ 不完善估值管线
- ⛔ 不建Web UI
- ⛔ 不做全A股每日推荐

## 三阶段路线图

### Phase 1 (3-4周) —「信号校准」
目标: 让买入信号方向正确

验收标准:
- 买入信号IC > 0.02 (fwd_5d)
- 回测Sharpe > 0.5
- 最大回撤 < 25%
- 参数非极端敏感

交付物:
1. factor_ic_diagnosis_report.html — 分项信号IC诊断
2. parameter_sensitivity_report.html — 连降天数/止损参数敏感性
3. v4_backtest_report.html — 修复后回测报告
4. config.py 参数更新

### Phase 2 (3-4周) —「信号输出」
目标: 系统从"能算"变"能用"

验收标准:
- 晨报"有机会"信号正确率>60%
- 减仓信号触发后3日跌幅>3%比例>50%
- 评分前3股票平均跑赢后3名 > 2%/周

交付物:
1. valuation_pipeline.py — 基础估值管线
2. daily_signal_output.py — 每日选股信号
3. daily_morning_report_v6.py — 升级版晨报含信号

### Phase 3 (3-5周) —「决策闭环」
目标: 量化 vs 实际操作形成学习回路

验收标准:
- 建议持仓1个月内跑赢沪深300概率>65%
- 信号 vs 实际操作偏差分析≤15%

交付物:
1. market_state.py — 市场状态分类器
2. news_sentiment.py — 公告情绪分析
3. weekly_review.py — 每周复盘报告
4. operation_log.md — 操作对比日志

## 成功标准

| 指标 | 失败线 | 及格线 | 优秀线 |
|------|--------|--------|--------|
| 回测Sharpe | < 0 | > 0.5 | > 1.0 |
| 买入信号IC (fwd_5d) | < -0.02 | > 0.02 | > 0.05 |
| 月度跑赢沪深300 | - | > 55% | > 70% |
| 晨报有效天数 | - | > 60% | > 80% |

**重要**: 月度收益率绝对值 ≠ 成功标准。IC/Sharpe是统计意义的——系统提高赚钱概率而非保证。
