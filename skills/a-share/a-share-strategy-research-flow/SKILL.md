# A股策略研发流程 — 中低频量化策略完整方法论

A股中低频量化交易策略研发的科学流程：规避未来信息、推进分析防过拟合、等分回测验证因子、交易成本贴近现实、策略评价体系。**基于《量化炼金术》（杨博理/贾芳，机械工业出版社 2017，A股 2010-15 全样本实证）**。

## When to Use

- 用户要开发/优化 A股择时或选股策略
- 用户要体检已有策略的过拟合/未来信息风险
- 用户要评估策略回测结果是否可信
- 做因子/策略的等分单调性验证

## 步骤 1 — 未来信息规避（回测前必查）

**核心原则：决策只能用 T 时刻前已知的信息。**

典型错误（回测中常见）：
| 错误 | 说明 | 对策 |
|---|---|---|
| 当日最低价买入 | 不到收盘无法确知最低价 | 用次日开盘/收盘决策 |
| 全样本优化后全样本回测 | 优化已"看过"未来 | 分样本存储（优化集/检验集） |
| 存活者偏差 | 数据库剔除退市股 | 检查样本是否含退市/停牌股 |
| "牛市中持有" | 事后诸葛亮 | 需事前可判定的市场状态规则 |

**检查清单**：
- [ ] 决策变量是否全部是 T-1 及更早可得
- [ ] 参数优化是否只用了训练集
- [ ] 股票池是否含退市股（存活者偏差）
- [ ] 财务数据是否按公告日对齐（防前视）

## 步骤 2 — 推进分析（walk-forward，防过拟合核心）

**原理**：时间轴滚动切分，白框（优化期）定参 → 灰框（检验期）验证 → 逐期推进。

执行步骤：
1. 总样本分为白框（如前70%）+ 灰框（后30%）
2. 白框内做参数优化（网格搜索）
3. 优化出的参数在灰框验证
4. 窗口推进（如按半年/逐年滚动）
5. **对比优化期 vs 检验期年化收益 → 量化过拟合程度**

**过拟合判定标准**：
| 优化期 vs 检验期 | 判定 |
|---|---|
| 检验期 ≈ 优化期 | ✅ 参数稳健 |
| 检验期明显 < 优化期 | ⚠️ 过拟合（差异越大越严重） |
| 检验期转负 | ❌ 严重过拟合，放弃参数 |

**实证参考**（均线趋势策略）：
- 全样本优化年化 40.37% vs 推进检验 5.53% —— 过拟合幅度惊人
- 仓位优化更甚：白框 266.76% vs 灰框 -35.86%
- 检验期按半年细分可定位过拟合时间段

## 步骤 3 — 等分回测（因子有效性验证）

**原理**：按因子值排序分 N 等份（3/10/30），等权组合，比较各组平均月度收益单调性。

执行步骤：
1. 月度调仓，按因子排序
2. 分 3/10/30 等份，等权组合
3. 计算各等份平均月度收益
4. 检查单调性 + 第1等份净值 vs 沪深300

**等分数选择**：太少（3）区分度不足，太多（30）噪声干扰——**多个等分交叉验证**。

**实证参考**（A股 2010-12~2015-06，全A月频）：
| 因子 | 3等分月收益 | 10等分(Q1→Q10) | 判定 |
|---|---|---|---|
| 市值 | 2.62/1.46/0.94% | 3.62%→0.71% 严格递减 | ✅ 小市值溢价 |
| 反转 | 1.95/1.71/0.84% | 第1份最高 | ✅ 反转有效 |
| 多因子 | 2.43/1.53/0.53% | 2.78%→最低 | ✅ 优于单因子 |

> 注意：2010-15 窗口后市场结构变化（2017 后小市值风格失效），需样本外验证。

## 步骤 4 — 交易成本敏感性（中低频必测）

**成本分类**：显性（佣金/印花税/经手费、买卖价差）+ 隐性（滑点、冲击成本）。

**实证参考**（A股 3.5 年）：
| 策略 | 无成本 | 万0.25 | 万0.5 |
|---|---|---|---|
| 均线趋势 | 12.18% | 10.17% | 8.20% |
| 自回归 | 35.82% | 33.36% | 30.94% |

**要点**：
- 中低频成本影响 ~2pp/手续费档，**远小于高频换手成本**——中低频定位天然有利
- 冲击成本与流动性相关：小盘/低流动性股冲击更大
- 回测至少测 3 档成本（0/万0.25/万0.5）画敏感性曲线

## 步骤 5 — 随机基线对比（LLM 信号校准检查）

**背景**（arXiv:2608.20304, Calibration-Induced Degeneracy）：LLM/ML 生成的原始信号经过 min-max 或 rank 校准后，**会把随机噪声放大成看似显著的 alpha**。信号值分布的非均匀性（如大量极值/聚集）会在校准后产生虚假的方向性。

**必做检查**（任何用 LLM 信号/评分做选股或择时的策略）：
1. **随机基线回测**：把信号序列随机打乱（permutation test，≥1000 次），或替换为同分布随机噪声，跑同样的回测管线
2. **对比基准**：真实信号 vs 随机基线 的收益/IC 分布。真实信号必须落在随机分布 95% 分位之外才算有效
3. **校准前后对比**：分别对 原始信号 和 min-max 校准后信号 计算 IC；若校准显著提升 IC 而原始信号 IC≈0 → 警惕校准幻觉
4. **极值检查**：信号值若大量集中在 [0,1] 两端（min-max 后）且中间稀疏 → 校准畸变信号，先看原始分布

**判定标准**：
| 检查结果 | 判定 |
|---|---|
| 真实 IC > 95% 随机基线分位 | ✅ 信号有效 |
| 真实 IC 落在随机分布内 | ⚠️ 信号疑似噪声 |
| 校准后 IC 突增但原始 IC≈0 | ❌ 校准幻觉，弃用 |

## 步骤 6 — 策略评价体系

| 维度 | 指标 | 备注 |
|---|---|---|
| 收益 | 整体收益率、年化收益率 | 硬指标，横向对比 |
| 风险（净值描述） | 最大回撤率、年化最大回撤、**回撤持续时长** | 实战派偏好 |
| 风险（统计） | 夏普、索提诺、信息比率 | 数学性质好 |
| 收益风险结合 | 年化收益/最大回撤、年化收益/年化最大回撤 | 作者偏好 |

**风险度量选择**：
- 最大回撤类：事后描述直观，但依赖样本期、易过拟合
- 方差/标准差类：建模优化更稳健，测算时间越长越接近真实风险
- 尾部风险：VaR、预期损失、损失概率

## 步骤 7 — 结构防泄漏护栏（LLM/Agent 策略发现必做）

**背景**（arXiv:2608.27734, Leakage-safe, search-aware assessment of LLM-driven trading strategy discovery）：LLM/Agent 自主搜索策略时，**自动性放大试验次数**——一次"搜索 + 自报最优"会产生几十上百次隐式回测，报告若不按真实试验次数 deflate 就会被自己的生产力放大成假 alpha。论文在两个真实 universe（453 只美股 PIT + 39 只多资产 ETF，含现实成本）上的核心实证：
- **提示词级防泄漏无效**：文本指令不能阻止生成策略在暴露未来信息的环境里消费它（"prompting an LLM to avoid look-ahead bias is a weak guardrail"）。
- **泄漏 oracle 骗过所有统计工具**：故意植入"当日已知明日收益"的特征（design Sharpe 34.7 / eval Sharpe 51.5 / **DSR=1.00**），Deflated Sharpe 与 PBO 完全拦不住——deflation 只纠正"诚实回测间的择优"，对信息集本身被污染毫无机制。**见到两位数 Sharpe 应先怀疑信息集，不是 alpha。**
- **结论：两道护栏互补、不可互相替代，且都必须结构性（system 层面 by construction）而非程序性（靠作者承诺/提示词）**：泄漏防护进"类型系统"（特征注册表），搜索强度进"账本 + deflate"（单一评估入口）。

**护栏 1 — 特征注册表白名单（结构禁绝未来函数）**
1. 凡策略可引用的特征/信号节点，一律先注册入库；注册时经"仅用 T 时刻前已知信息"的确定性校验（代码执行，不靠提示词自觉）：
   - 财务指标按**公告日（ann_date）**对齐，不是报告期（period）；外部事件/龙虎榜/资金流等滞后披露数据按**发布日**对齐；价格信号只用 ≤T 的 bar，信号 T 生成、**T+1 起执行**（论文引擎全局施加一日执行滞后；universe 按滚动流动性点对点重选，成员资格不含未来信息）。
   - 校验不通过的特征（未来函数）**从可选集排除**，而不是标注警告：论文设计下 look-ahead 是"不可表达"（inexpressible）而非"被劝阻"。
2. Agent 只能经注册表校验的动作面行动（add_feature / add_node / add_signal_term / select_strategy…），每步调用即校验（参数 schema、引用解析、组合名单），非法调用返回结构化错误、模型在循环内自修。附带收益：①参数幻觉从"事后惩罚"变"事前消除"（对照：无校验的 JSON 生成器 60/60 提案全被拒；有校验后 99/100 与 80/100 提案有效）；②**搜索可观测**——每个候选都过同一评估入口，账本"by construction"完备。
3. **自检（泄漏对照 arm）**：故意在系统里注册一个"明日收益"特征做成对照策略。若该对照在统计工具（DSR/PBO）下仍"显著"（论文中 Sharpe≈35 的 oracle 全通过），说明只有结构护栏能拦——统计 deflate 与泄漏防护是互补品，不是替代品。

**护栏 2 — 搜索账本 + deflate（搜索感知的诚实评价）**
1. **试验账本（trial ledger）**：记录搜索期间每一次策略评估（候选组合、design-window 绩效、时间戳）——**包括被否决的组合与网格点**，不是"最终报告的策略数"。论文 E3：100 候选 + 基准 arm，账本 N=102。
2. **Deflated Sharpe（DSR）**：报告绩效按自己的试验次数 deflate。DSR = PSR(SR*_0)，择优阈值 SR*_0 = √V[(1−γ)Φ⁻¹(1−1/N) + γΦ⁻¹(1−1/(Ne))]，随试验数 N 与各试验 Sharpe 离散度 V 上升。推论：**N=1（预注册单一假设）阈值塌缩到基准、几乎零 deflate**——框架奖励"先有经济假设再验证"，惩罚"暴力搜索千个变体却只报最好那个"。
3. **蒸发曲线（evaporation curve）**：按搜索顺序画两条线——截至第 k 次试验的**最佳 design Sharpe**（运行最大值，只升不降）vs 第 k 次试验的 **deflate 阈值**（随 k 与离散度上升）。阈值追上/超过最佳 Sharpe 处 = 搜索强度已跑赢自己的发现（边际试验成本 > 其证据）。论文 E3：best IS Sharpe 从 -0.07 爬到 1.69，deflate 阈值追到 1.21，DSR=0.86 < 0.95 认证线；样本外 Sharpe 崩到 0.18（4 年 +4.7% vs 买入持有 +40.8%）——"这类数字是论文敢当头条的，诚实评估不给认证"。**加预算不削弱会计，反而收紧**：同离散度下 10⁴ 候选的阈值约为 100 候选的 1.5×。
4. **PBO/CSCV**：design 窗分 S=16 块，遍历所有组合的样本内/样本外切分，取样本内最优者的样本外排名 ω 的对数比 λ=ln(ω/(1−ω))，PBO=P(λ≤0)；候选矩阵的列数 = 账本试验数（强制不变量）。
5. **三种失败模式三种工具**（论文 E3/E4/E5 实证）：selection luck（样本外盈利但与自己的试验次数比仍是抽奖）→ DSR 抓；rank 退化（样本内赢家样本外排名掉队）→ PBO 抓；绝对收益崩塌（排名保住但 edge 没了，PBO 反而低）→ 样本外 bootstrap CI 抓。三个都算，一个数不够。
6. **威力算术（power arithmetic）**：Sharpe 的 t 统计量 ∝ SR·√years——SR=0.6 的中等 edge 约需 **11 年样本外**才到 t≈2，deflate 还加码；4 年窗几乎无法认证中等低频 alpha（论文 E1-E4 全部 reject、只认证被动基准；9 年窗才可能认证 SR≈0.7）。"不认证 ≠ 不存在"，报告的是证据量。

**必做检查（追加进"验证 checklist"）**：
- [ ] 特征白名单：策略引用每个特征前经"仅当时已知"自动校验入库；未来函数在可选集外（结构性，非提示词）
- [ ] 泄漏对照 arm：故意植入"明日收益"特征——若 DSR/PBO 仍放行（论文：Sharpe 35 oracle 全通过），说明统计工具拦不住泄漏，必须结构禁绝
- [ ] 搜索账本：每次评估（含被拒/网格点）都记录，报告绩效按真实试验数 deflate
- [ ] 蒸发曲线：best IS Sharpe 爬升 vs deflate 阈值——阈值追上即停止声称（论文 E3 阈值 1.21 追到 1.69 之下仍差一口气，DSR 0.86）
- [ ] 样本外证据年限：SR·√years≈2 才是"能认证"的最低门槛；窗不够长时只报"证据不足"，不报"有效"

**A股落地映射**：多轮参数优化/多 Agent 评审/因子挖掘（quant-alpha-factory、multi-agent 流程等）产生多个候选时，DSR/PBO 的 N 取**该搜索期全部 design 评估次数**；把"网格搜索了多少个点 + 试了多少个变体"写进回测报告的统计块；预注册假设（先写假设再验证，如本流程推进分析白框定参后灰框只验一次）天然 N 小、deflate 轻——这正是推进分析 + 本护栏的组合价值。

> 论文结论（供引用）：453 股 PIT + 39 ETF、真实成本、两个前沿模型、搜索预算至 100 候选、5 次重复——**被动基准被认证（样本外 CI 排除 0），所有 LLM 发现策略全被拒**；同一套工具也给人类生产规则系统（84 节点状态机规则引擎）同等待遇并给出双向结论。来源：~/paper_library/q-fin/2608.27734/

## 仓位与组合优化（进阶）

- **凯利公式**：最优下注 = 胜率优势/赔率
- 仓位优化实证：降低仓位（标准差阈值 0.08→0.02）可减少过拟合（灰框 -35.86%→+12.18%）
- **多因子风险模型**：协方差矩阵 Σ = F·B·F' + A（因子协方差 + 特质方差对角阵），解决马科维茨参数估计过多问题
- Black-Litterman 适合大类资产配置，不适用个股组合

## 验证 checklist（回测报告必备）

- [ ] 无未来信息（数据可得性日历对齐）
- [ ] 推进分析完成（优化期 vs 检验期对比）
- [ ] 等分回测单调性检验
- [ ] 成本敏感性 ≥3 档
- [ ] **随机基线对比（LLM 信号必做：permutation test 或校准前后 IC 对比）**
- [ ] 回撤时长已记录
- [ ] 存活者偏差已检查

## Pitfalls

- **全样本优化 = 未来信息**：这是最隐蔽的回测错误
- **检验期收益为负 ≠ 策略无效**：可能只是过拟合信号，先降参数量
- **最大回撤指标易过拟合**：别用它做优化目标函数（数学性质差）
- **停牌/涨跌停处理**：回测需模拟无法交易的情况，避免虚增收益
- **单月/单年高收益不可信**：看跨周期稳定性
