# A股买入卖出点案例分析

## 触发条件

用户提供如下格式的案例数据：
- **股票代码 + 日期 + 买入/卖出点位**
- 标准格式：`{代码},{名称},{买入日期},{卖出日期},成为案例N`
- 单个日期格式：`{代码},{名称},{日期},收盘价和开盘价是多少?`
- 设定买入/卖出：`设定这个是买入点` / `作为买入卖出点的一个案例`
- 所有案例均以 **开盘价** 作为买入/卖出价格

## 分析流程（按序执行）

### ① 基础行情确认
- 通过 Tushare `daily` 接口获取该日期开盘/收盘/最高/最低/涨跌幅
- 确认该日期为有效交易日

### ② 现有因子检查
- 查询 `stock_data.db` 中的因子字段（技术面、基本面）
- 启动 `strategy_library/evaluation/ic_analyzer.py` 查看各因子IC表现
- 重点观察：MACD、KDJ、RSI、BOLL、VOL、主力资金等在该时间点的状态

### ③ 资金流分析
- Tushare `moneyflow_dc` 或 `moneyflow_ths` — 查看当日大单/中单/小单资金流向
- 主力资金净流入/流出情况
- 资金流向强度（净流入率）

### ④ 板块热度
- 同花顺/东财概念板块涨幅排名（`moneyflow_ind_dc` / `moneyflow_cnt_ths` / `ths_daily` / `dc_index`）
- 所属板块资金流入程度
- 该股在板块中的领涨/跟风位置

### ⑤ 公告与新闻
- Tushare 公告接口（`anns_d`）：检查业绩预告、增减持、重大合同等
- Tushare 快讯/新闻（`news` / `major_news`）：当日前后相关消息面驱动

### ⑥ 外部挖掘（可选）
- 搜索GitHub上类似策略的开源项目，借鉴因子思路
- 对比其他公开策略的信号规则

## 输出框架

每次分析结果按以下三档呈现：

| 维度 | 内容 |
|------|------|
| 🟢 **买入信号** | 什么因子/指标/事件触发了买入 |
| 🔴 **卖出信号** | 什么因子/指标/事件触发了卖出 |
| 🟡 **持有信号** | 什么条件下应继续持有 |

## 重要约束

### 买入/卖出日期浮动规则
- 每个案例的买入/卖出日期允许 **前后±3个交易日** 浮动，用于信号检测
- 因子信号可能在实际买卖日的前后3天内出现，不要死锁在单一日期
- 这对样本量有一定放大效果，降低了对精确日期的依赖

### 案例数据存储
- **不要自动保存到持久记忆（memory）** — 必须先询问用户存储位置：
  - 保存为 skill（适合长期参考的方法论）
  - 写入本地文件（如 `~/my_quant_system/案例/`）
  - 留在此会话聊天记录中（默认选项）
- 用户确认"就留在这个会话里"后，仅在会话上下文中保留，不写任何持久化存储

### 分析顺序
严格按照 基础→因子→资金流→板块→公告→外部的顺序，前面的维度有结论后再进入下一层，避免信息过载。

### 两阶段工作流

#### 阶段一：案例积累
- 先收集足够的买入/卖出案例（建议≥10个，理想≥20个）
- 案例数量不足时，派出 **3个Agent并行评估** 最低需要数量和推荐收集方向
- 每个Agent从不同角度（统计样本量、因子分析需求、行业扩展方向）给出建议
- 综合3个Agent意见后，确定目标案例数量，继续收集
- 排除约束：默认不收集 **科创板(688xxx)** 和 **北交所(8xxxxx)** 股票

#### 阶段一·五：探索性因子预研（6~15个案例时）
- 案例数不足20时，可做 **模式预研** 而非统计验证
- 用 `execute_code` 或 `delegate_task` 并行收集多只股票的 `moneyflow_dc` 资金流数据
- 观察买入点前20个交易日、卖出点前20个交易日的共性规律
- 输出为**定性观察报告**，用于指导后续因子挖掘方向，不做统计断言

#### 阶段二：因子挖掘
- 达到足够案例数量后，再考虑技术路线
- 使用IC分析框架评估各因子有效性
- 涉及的路线包括：技术面因子复现、资金流因子、板块轮动因子等

### 用户核心策略诉求（2026-07发现）

来自用户的明确表述：
1. **标的筛选**：找准当下**资金流入最多的板块的龙头股**作为交易标的
2. **操作维度**：不止买入卖出，还需要 **调仓信号、减仓信号、继续持仓信号**
3. **行为挑战**：用户交易过这些股票但"拿不住"——持有信号和仓位管理信号是关键痛点
4. **板块排除**：默认排除 **科创板(688xxx)** 和 **北交所(8xxxxx)**

## 预研数据批量收集技巧

当有多个案例需要同时分析时：
- 用 `mcp_tushareMcp_moneyflow_dc` 同时查询多只股票的买入/卖出日前20个交易日资金流
- 用 `mcp_tushareMcp_stk_factor_pro` 查询买入/卖出日前后的技术因子快照
- 观察到共性模式后，写入 `references/moneyflow-patterns.md` 作为模式库积累

已积累的模式见 `references/moneyflow-patterns.md`，包括：

- 买入前的"恐慌见底→反转"模式

- 卖出前的"连续多日大单净卖出"预警
- 卖出前的"拉高诱多 + 散户接盘"预警
1. 本地 SQLite 数据库（stock_data.db 等）
2. Tushare MCP 接口
