# 板块TOP3上榜后龙头股持有期回测

## 回测框架
脚本: `scripts/backtest_sector_leader.py`
数据源: THS板块排行 + `ths_member`成分映射 + `moneyflow_daily.net_mf_amt`(个股主力净流入) + `daily_kline.close`(股价)

## 策略
当某概念板块出现在每日净流入TOP3时，在收盘买入该板块的龙头股
（板块内当日主力净流入最大的1~3只成分股），持有N个交易日后卖出。

## 回测参数

| 参数 | 值 |
|:----|:----|
| 回测区间 | 2026-04-01 ~ 2026-07-10（72个交易日） |
| 板块排行源 | THS (`sector_moneyflow_ths`) |
| 龙头识别 | `ths_member` + `moneyflow_daily.net_mf_amt` |
| 持有期 | 1 / 3 / 5 / 10 / 20 交易日 |
| 每板块龙头数 | Top 1 / Top 3 |
| 买入点 | 收盘价（信号日） |
| 卖出点 | 收盘价（N 个交易日后） |
| 排除板块 | 融资融券/沪股通/深股通/MSCI/HS300/标准普尔等31个宽基指数 |

## 关键修复记录

1. **moneyflow_daily 缺 `close` 列**: 股价只能从 `daily_kline` 单独查询
2. **日期格式不匹配**: `daily_kline.date` 是 YYYY-MM-DD，`sector_moneyflow_ths.trade_date` 是 YYYYMMDD，需 `fmt_date()` 互转
3. **`_calc_stats` 误写 `'trades': trades`**: 列表被赋给计数键，导致 `:>5` 格式化报错（`run_all`中遗留的调试代码）
4. **回测卡"无有效样本"**: 两个原因：TOP3被宽基指数霸占（需EXCLUDE_SECTORS）+ 单个交易日找不到有正资金流的成分股（改用 `net_mf_amt`）
5. **trade_cal 重复行**: 交易日表有重复，导致连续天数统计翻倍（修复: `SELECT DISTINCT cal_date`）

## 回测框架结构

`BacktestEngine` 类:
- `get_top_sectors()`: 获当日TOP3板块（排除指数型）
- `get_leader_stocks()`: 查成员+净流入最大的N只
- `get_holding_returns()`: 查daily_kline算持有期收益率
- `run(hold_days, top_n)`: 跑单一参数组合
- `run_all()`: 遍历所有组合
- `_calc_stats()`: 计算胜率/夏普/最大回撤等
- `analyze_by_sector()`: 按板块汇总
