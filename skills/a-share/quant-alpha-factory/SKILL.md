# Quant Alpha Factory — 量化因子设计与评估方法论

把"想法"转化为可回测、可上线、可持续的 alpha 因子的完整方法论。**基于 WorldQuant 实践（Finding Alphas）**，适用于用户的因子工厂项目（候选→验证→上线→淘汰生命周期）。

## When to Use

- 用户提出新因子想法（"试试这个信号"）
- 用户要评估/淘汰因子库中的候选因子
- 用户要迭代优化已有因子的表现
- 构建自动化因子搜索/生成管线

## 核心流程：alpha 五步闭环（Idea→Performance）

```
① Idea → ② Raw alpha → ③ Position → ④ PnL → ⑤ Performance → Revise 回到①
```

| 步骤 | 动作 | 关键工具/操作 |
|---|---|---|
| ① Idea | 提出可验证的市场假设 | 市场逻辑/统计规律/数据驱动 |
| ② Raw alpha | 转数学公式 | 如 `-1*(close(t)-close(t-5))` |
| ③ Position | 标准化/去极值/中性化 | rank化、行业中性（Sum=0）、clamp |
| ④ PnL | 回测 | 记录收益/回撤/换手/盈利天数 |
| ⑤ Performance | IR/tvr/ret 评估 | **IR≥1.5** 为优；不达标→Revise |

**迭代优化链参考**（5日反转案例，美股2010-15）：
| 版本 | 操作 | 年化 | IR | 最大回撤 | 换手 |
|---|---|---|---|---|---|
| v1 | 原始信号 | 31.2% | 1.00 | 39.2% | 63.3% |
| v2 | +行业中性化 | 10.2% | 1.37 | **8.7%** | 63.3% |
| v3 | +rank化 | 9.9% | 1.76 | 5.8% | 59.2% |
| v4 | +3日decay | 10.4% | **1.82** | 7.7% | **42.2%** |

> 行业中性化牺牲收益换稳健；rank 化提 IR；decay 降换手。每一步评估后可回到 Idea 修改。

## 因子评估四指标（硬门槛）

| 指标 | 公式 | 达标线 | 用途 |
|---|---|---|---|
| 信息比率 IR | mean(日收益)/std(日收益)×√256 | ≥1.5 | 风险调整后收益 |
| 日换手率 tvr | 日均成交额/BookSize | 越低越好 | 成本敏感性 |
| 收益 ret | 年化收益率 | 为正 | 绝对收益 |
| 最大回撤 | 净值峰谷比 | 越小越好 | 风险 |

## 换手成本铁律（ch7 实证，必查）

**高换手 + 小盘流动性差 = 成本毁灭**。实证：5日反转 alpha 计成本后 Top3000 从 +576M 变 **-1061M**（回撤-212%）；Top1000 仅亏-82M。

- 检查顺序：先看 tvr → 若 >30% 必须做成本敏感性测试（0%/0.25%/0.5%）
- decay（信号多日平均）是降换手首选工具：3日 decay 换手 63%→42%
- 低换手反例：EarningsMom（tvr 35%）9年夏普1.59/回撤-7.28% 稳健正收益

## 五分位（quintile）稳健性检验

按 alpha 值分 Q1-Q5 五组，观察收益/夏普分布：

| 分布形态 | 判定 | 动作 |
|---|---|---|
| 单调递减（Q1 35%→Q5 -25%） | ✅ 稳健 alpha | 可上线 |
| 只有尾部差异（Q2-Q4 平坦近0） | ⚠️ 不稳健 | 依赖噪声/稀有事件，淘汰 |
| 非单调过山车（Q2最佳Q4最差） | ❌ 过拟合 | 样本内特定，立即淘汰 |

## 相关性控制

- **信号数量陷阱**：信号从 10→1000万，最大相关性 0.07→0.23（边际递减）——盲目堆信号必然偶然高相关
- 同一想法衍生的 alpha 天然高相关 → 组合需分散
- PnL 相关性用 2-4 年长窗口；alpha 值相关性用短近期窗口
- 追求**低相关独立信号**才是纯 alpha 来源

## 因子边际效用递减（国信45 实证，2026-08 补充）

**因子并非越多越好**——>90% 的组合增因子后反而变差。⚠️ 口径修正（2026-08-23 评审）：原文 3.5%/9.8%/2.3% 是组合**跑赢其全部子组合的占比**（非增因子收益增益）：

| 因子数 | 跑赢全部子组合的组合占比 | 含义 |
|---|---|---|
| 三因子 | **3.5%** | 仅极少数三因子组合强于其双因子子组合 |
| 四因子 | **9.8%** | 仅极少数四因子组合强于其全部子组合 |
| 五因子 | **2.3%** | 比例最低，几乎无组合受益 |
| 三/四/五因子整体 | **>90% 组合增因子后变差** | 边际效用为负 |

- **静态最高累计收益**（2005-07-12 起）：三因子 545.6% / 四因子 619.8% / 五因子 547.9% —— 四因子静态最优
- **动态区分度调整后**：四因子 730.4%、五因子 758.6%（动态五因子更高；730.4% 是动态结果，勿当作静态四因子峰值）
- **区分度阈值 0.05**：动态打分时区分度 < 0.05 的因子被抑制（原文注明该阈值未经敏感性分析，是默认值）
- 年化波动 30-33% 为各因子数组合平均，非四因子专属
- 含义：选因子重"正交增量"而非"数量堆叠"；与上方信号数量陷阱（相关性边际递减）互为印证
- 验证方法：加因子后看**组合层面**收益变化（非单因子 IC），批量对比 3/4/5 因子组合

## 自动化搜索纪律（因子工厂）

1. 输入数据类别不宜过多（每类数据只派少数因子）
2. 用无量纲比率（rank/标准化），不用原始价格
3. 限制搜索空间，避免组合爆炸
4. 简单 alpha 优先（复杂 ≠ 更好）
5. 长回测期（跨牛熊）
6. **按批次评估**而非单个 alpha 表现（批次分散+提升）
7. 敏感性测试 + 显著性检验（防过拟合）
8. 批次层面做分散和迭代改进

## 常见偏差清单（防坑）

| 偏差 | 表现 | 对策 |
|---|---|---|
| 前视偏差 | 用了未来信息 | 数据可得性日历对齐 |
| 数据挖掘 | 信号多→偶然相关 | 五分位+敏感性检验 |
| 讲故事 | 事后找理由 | 先有假设再验证 |
| 确认偏差 | 只留有利证据 | 保留完整回测日志 |
| 熟悉度偏差 | 偏好熟悉的股票 | 全池覆盖 |
| 羊群效应 | 跟随热门信号 | 相关性监控 |

## 验证 checklist

- [ ] 五步闭环走完（Idea→Performance）
- [ ] 四指标齐全（IR/tvr/ret/回撤）
- [ ] 换手 >30% 时已做成本敏感性测试
- [ ] 五分位分布单调（或确认尾部差异风险）
- [ ] 与现有因子相关性 <0.7
- [ ] 长回测期 + 样本外验证通过

## Pitfalls

- **收益高 ≠ 好因子**：高收益常伴随高换手，成本后可能归零或巨亏
- **行业中性化是双刃剑**：降回撤但砍收益，看目标用途决定
- **五分位只尾部差异**是最隐蔽的不稳健信号，务必检查 Q2-Q4
- **decay 不是万能**：过度平滑会衰减信号本身，需平衡
