# Quant Alpha Factory — 量化因子设计与评估方法论

把"想法"转化为可回测、可上线、可持续的 alpha 因子的完整方法论。**基于 WorldQuant 实践（Finding Alphas）**，适用于用户的因子工厂项目（候选→验证→上线→淘汰生命周期）。

## When to Use

- 用户提出新因子想法（"试试这个信号"）
- 用户要评估/淘汰因子库中的候选因子
- 用户要迭代优化已有因子的表现
- 构建自动化因子搜索/生成管线

## 核心流程：alpha 五步闭环（Idea→Performance）

```
① Idea → ② Raw alpha → ③ Position → ④ PnL → ⑤ Performance → Revise 回到①
```

| 步骤 | 动作 | 关键工具/操作 |
|---|---|---|
| ① Idea | 提出可验证的市场假设 | 市场逻辑/统计规律/数据驱动 |
| ② Raw alpha | 转数学公式 | 如 `-1*(close(t)-close(t-5))` |
| ③ Position | 标准化/去极值/中性化 | rank化、行业中性（Sum=0）、clamp |
| ④ PnL | 回测 | 记录收益/回撤/换手/盈利天数 |
| ⑤ Performance | IR/tvr/ret 评估 | **IR≥1.5** 为优；不达标→Revise |

**迭代优化链参考**（5日反转案例，美股2010-15）：
| 版本 | 操作 | 年化 | IR | 最大回撤 | 换手 |
|---|---|---|---|---|---|
| v1 | 原始信号 | 31.2% | 1.00 | 39.2% | 63.3% |
| v2 | +行业中性化 | 10.2% | 1.37 | **8.7%** | 63.3% |
| v3 | +rank化 | 9.9% | 1.76 | 5.8% | 59.2% |
| v4 | +3日decay | 10.4% | **1.82** | 7.7% | **42.2%** |

> 行业中性化牺牲收益换稳健；rank 化提 IR；decay 降换手。每一步评估后可回到 Idea 修改。

## 因子评估四指标（硬门槛）

| 指标 | 公式 | 达标线 | 用途 |
|---|---|---|---|
| 信息比率 IR | mean(日收益)/std(日收益)×√256 | ≥1.5 | 风险调整后收益 |
| 日换手率 tvr | 日均成交额/BookSize | 越低越好 | 成本敏感性 |
| 收益 ret | 年化收益率 | 为正 | 绝对收益 |
| 最大回撤 | 净值峰谷比 | 越小越好 | 风险 |

## 换手成本铁律（ch7 实证，必查）

**高换手 + 小盘流动性差 = 成本毁灭**。实证：5日反转 alpha 计成本后 Top3000 从 +576M 变 **-1061M**（回撤-212%）；Top1000 仅亏-82M。

- 检查顺序：先看 tvr → 若 >30% 必须做成本敏感性测试（0%/0.25%/0.5%）
- decay（信号多日平均）是降换手首选工具：3日 decay 换手 63%→42%
- 低换手反例：EarningsMom（tvr 35%）9年夏普1.59/回撤-7.28% 稳健正收益

## 五分位（quintile）稳健性检验

按 alpha 值分 Q1-Q5 五组，观察收益/夏普分布：

| 分布形态 | 判定 | 动作 |
|---|---|---|
| 单调递减（Q1 35%→Q5 -25%） | ✅ 稳健 alpha | 可上线 |
| 只有尾部差异（Q2-Q4 平坦近0） | ⚠️ 不稳健 | 依赖噪声/稀有事件，淘汰 |
| 非单调过山车（Q2最佳Q4最差） | ❌ 过拟合 | 样本内特定，立即淘汰 |

## 相关性控制

- **信号数量陷阱**：信号从 10→1000万，最大相关性 0.07→0.23（边际递减）——盲目堆信号必然偶然高相关
- 同一想法衍生的 alpha 天然高相关 → 组合需分散
- PnL 相关性用 2-4 年长窗口；alpha 值相关性用短近期窗口
- 追求**低相关独立信号**才是纯 alpha 来源

## 因子边际效用递减（国信45 实证，2026-08 补充）

**因子并非越多越好**——>90% 的组合增因子后反而变差。⚠️ 口径修正（2026-08-23 评审）：原文 3.5%/9.8%/2.3% 是组合**跑赢其全部子组合的占比**（非增因子收益增益）：

| 因子数 | 跑赢全部子组合的组合占比 | 含义 |
|---|---|---|
| 三因子 | **3.5%** | 仅极少数三因子组合强于其双因子子组合 |
| 四因子 | **9.8%** | 仅极少数四因子组合强于其全部子组合 |
| 五因子 | **2.3%** | 比例最低，几乎无组合受益 |
| 三/四/五因子整体 | **>90% 组合增因子后变差** | 边际效用为负 |

- **静态最高累计收益**（2005-07-12 起）：三因子 545.6% / 四因子 619.8% / 五因子 547.9% —— 四因子静态最优
- **动态区分度调整后**：四因子 730.4%、五因子 758.6%（动态五因子更高；730.4% 是动态结果，勿当作静态四因子峰值）
- **区分度阈值 0.05**：动态打分时区分度 < 0.05 的因子被抑制（原文注明该阈值未经敏感性分析，是默认值）
- 年化波动 30-33% 为各因子数组合平均，非四因子专属
- 含义：选因子重"正交增量"而非"数量堆叠"；与上方信号数量陷阱（相关性边际递减）互为印证
- 验证方法：加因子后看**组合层面**收益变化（非单因子 IC），批量对比 3/4/5 因子组合

## 自动化搜索纪律（因子工厂）

1. 输入数据类别不宜过多（每类数据只派少数因子）
2. 用无量纲比率（rank/标准化），不用原始价格
3. 限制搜索空间，避免组合爆炸
4. 简单 alpha 优先（复杂 ≠ 更好）
5. 长回测期（跨牛熊）
6. **按批次评估**而非单个 alpha 表现（批次分散+提升）
7. 敏感性测试 + 显著性检验（防过拟合）
8. 批次层面做分散和迭代改进

## regime 稳健超参选择（跨 regime BO 协议）

**背景（论文 2608.27076，Le Grice 2026）**：现有超参选择只看**单一验证窗的预测精度/IC**，不针对 regime 稳健性。论文对 5 类模型（LR/XGBoost/MLP/TabNet/FT-Transformer，2015–2024 训练、2025 留出 OOS，约 300 只美股大盘日频）用 **BO 目标 = 跨 3 个可区分 regime 的交易绩效**选参，得到两个硬事实：**① 没有任何单一 tabular DL 架构打败梯度提升树**；② **XGBoost + TabNet 秩聚合 Hybrid 最强**（年化 51.26%、Sharpe 2.44、CAPM α=0.423, p=0.011、近零 beta——超额来自选股而非市场暴露）。给本工厂的启示：当"因子组合"环节上 ML 模型时，目标函数选错（单窗 IC）比模型选错更伤。

### 协议步骤

**① 统计划分 3 个可区分 regime（不做推理期 regime 检测）**：以日历块（论文=验证年 2022/2023/2024）为 regime 代理 + **expanding window**（每折用 2015~前一年底全部数据训练、评估目标年；rolling 会丢弃早期数据，偏离生产条件；随机 k-fold 会给时序引入前视，禁用）。折边界做 **1 天 purge**（label 窗口跨界）。然后**两两 KS 检验**（日收益 + 5 日实现波动率分布）验证各折确实不同——论文全部 p<0.001；再与 OOS 期比一次 KS 确认分布漂移存在（否则"跨 regime"无从谈起）。⚠️ 论文 §2.2 明确批评"推理期 regime 检测→模型选择"的路线：检测误差会传播进模型选择、且每态多一层调参会过拟合历史 regime。A 股落地：选 3 个可区分的年度块（如 2022 熊/2023 震荡/2024 修复），用沪深 300 或中证 800 的收益+波动率 KS 背书。

**② BO 目标 = 最差/目标 regime 的交易绩效（不是单窗 IC）**：每次 trial 在**全部 3 个 fold 上训+按统一组合构建回测**，复合分（论文式，权重与目标值**实验前固定**——权重也调参=目标函数自身过拟合）：

```
Score = 0.4·(r̄/0.15) + 0.4·(s̄/1.5) − 0.2·(d̄/0.10)   ← 均值项（r̄=平均年化收益, s̄=Sharpe, d̄=最大回撤）
        − Pr − Ps − Pd − Pfloor                        ← 防"平均好=一个 regime 暴赚另一个崩"
Pr   = 1.5·(max_i|min(0, r_i)| / 0.15)²   任一 fold 收益为负即触发
Ps   = 1.5·(max_i|min(0, s_i)| / 1.5)²
Pd   = 1.0·(max_i|max(0, d_i−0.15)| / 0.15)²   回撤>15% 触发（10~15% 只减分不淘汰）
Pfloor = 10.0 若 ∃ fold: r_i < −0.20            硬地板：单 regime 亏>20% 直接淘汰
```

   目标值对标被动基准（论文：年化 15% > 指数均值 14.3%；Sharpe 1.5 > 0.93；回撤 10% < 13.1%）——A 股用同期宽基年化/Sharpe/年回撤标定。惩罚的二次形式让"20% 回撤付出 4 倍于 10% 的代价"，硬地板杜绝单 regime 崩盘配置。采样用 TPE（论文 Optuna，30 trials）；**组合头寸数也进搜索空间**（论文 n∈[5,8] 与模型超参联合调）。

**③ 架构基线纪律（避免重蹈论文结论）**：若管线想从 GBDT 换 DL，先跑 **XGBoost+TabNet 秩聚合 Hybrid** 作基线再谈单个架构——论文 OOS 实证单架构无人胜过 XGBoost。秩聚合实现：每日把各模型多/空**信号概率分别做截面 rank → 跨模型平均 rank → top-n 选股**；不要平均 raw 概率（校准差异会让差模型主导信号）。集成选择：先剔除"任一验证 regime 收益为负"的组合，余下按复合分排序取最优。

**④ 输入噪声敏感性测试协议（上线前必测，论文 §3.4.2）**：向**标准化后的测试特征**注入高斯噪声，σ ∈ {0.05, 0.10, 0.20, 0.50}（按各特征自身 SD 的比例），× 20 个随机种子；每个水平记录组合收益/Sharpe/最大回撤 + 预测概率分布的 JS 散度（漂移量）；另跑 **random null 对照**（全部特征换纯高斯噪声）确认模型学的是信号不是噪声。判读基准：论文实证"性能随噪声**缓慢退化**、越过某阈值才崩塌"——若你的信号在 σ=0.10 已大幅崩，说明供应商口径不一致或管线延迟会在实盘杀死策略。

**⑤ 时段稳定性（OOS 内再切 regime）**：把 OOS 期按季切分、两两 KS 证实各季分布不同；报告**每季多/空信号 precision 是否都高于随机基线**（论文：4 个季度全高于随机基线才算 regime 稳健）——单年总量 Sharpe 无法区分"稳健配置"与"恰好适合这一年"的配置。

**新增 Pitfalls 条目**：单验证窗 IC 调参 = 选"最像历史的超参"；跨 regime 复合分 + 二次惩罚 + 硬地板三者缺一，BO 就会找到"一 regime 暴赚掩盖另一 regime 崩盘"的配置。

## 发现系统级评估纪律（P1/P2/P3）——当评估对象是"自动化因子发现系统"时

**背景（论文 2609.00731，Pan/Ding/Giesecke 2026）**：现有评估只回测**输出**（因子或交易），不回测**产生输出的自主发现系统**。论文核心论点：当"研究者本身是模型"时，point-in-time 纪律要套**两层嵌套循环**——内环=发现循环（假设→形式化→评估），外环=跨历史决策日重跑整个内环。只"发现一次 + 留出测试窗"证明了因子集，**没证明产生它的过程**（过程可能在固定切分上恰好走运一次，输出层面不可见）。适用场景：你的因子工厂接入 LLM/自动化生成候选，或要对 RD-Agent/AlphaAgent 这类管线做验收——评估对象从单因子升级为"发现系统"。

### P1/P2/P3 三原则（论文 §2.3）

- **P1 point-in-time 数据**：决策日 t 之后才可观测的特征不得进入内环。落地（论文 §3.3.2）：候选公式在**沙箱命名空间**执行，只允许访问其静态读到的列；**look-ahead firewall**（确定性 AST 走查，7 类规则 + 白名单；论文实例：`rolling(center=True)` 的中心窗被判 look-ahead）；另有 **Alignment Checker** 要求逐行 trace，且引用的代码子串必须真实存在（论文踩坑：checker 曾引用公式中不存在的 `.shift(1)` 误杀好公式）。
- **P2 point-in-time 过程**：外环真实存在——内环在每个历史决策日**可重执行、可评分**。协议（论文 §3.5）：从同一初始库与门出发，每 k 个月 **repropose**（新 seed → 新公式 → 重跑验证门 → 库增长），组合器每 j 个月独立 refit（j 整除 k）；每个决策日只条件于止于该日的滑动样本窗。关键：**状态跨事件携带**（库=明天的构件、novelty 参照集随新 admits 更新、lessons 经 reflector 持久化）——丢状态冷重启的 rolling 只是若干次独立静态 run 的拼接，测的是更弱的主张。论文实证：年度 re-discovery（k=12）+ 4 月 refit（j=4）对比 identical-library 静态基线。
- **P3 头号指标只用外环未触碰样本**：宣传数字必须来自**两层循环都没碰过的 split**。论文布局：内环 in-sample 2010–2019（其中 out-of-decade 切分故意测跨 regime 一致），OOS 窗 59~71 个月。⚠️ backbone 泄漏是"软的而非没有"：单一代 LLM 全角色复用残留一般知识偏差——用**特征描述而非已实现收益**做 propose 可贴近安全端。全部阈值 ex-ante 锁死、**见过任何 OOS 结果前固定**（SEADS 内部 gate 9 项顺序+阈值锁定，novelty 0.7 等；Rank-IC 条随累计试验数 Bonferroni 动态）。

### 参考架构（对照自己管线缺口逐项自查；论文 B1–B5 构件 + SEADS 实例）

生成(Planner 定广度 70% explore/30% exploit + Proposer 定深度) → **sanity**（结构预检 + point-in-time 沙箱 + look-ahead firewall + 对齐检查）→ **验证门**（9 项按序全过才准入：重复指纹 → self-collapse 检查[最终公式与自身声明输入之一的 plain rank 相关 ≥0.95 即拒] → coverage → Rank-IC t 值[Bonferroni] → out-of-decade regime 一致 → novelty vs 参照集 → partial-IC vs top-K 控制 → Fama-MacBeth t → Rank-IC/partial-IC/FM β 符号一致）→ **自进化**（只变异 near-pass：过了最低进度线或只挂在特定门阶段的候选；反馈**点名失败阶段**而非标量适应度；提前停）→ **状态组合**（库积累 + Ridge α=1 组合器，刻意不用 XGBoost——复现优先）。生成与裁判必须分离：门（B4）的裁决是**证据**，不是生成器对自己的评价。

### 多轴联合评分（无单指标排名；论文实证"无一致排名"）

单指标排名不可靠（论文：performance 轴 Panel A 由 Beyond Prompting 0.41 领先、Panel B 由 SEADS 0.16 领先；按 novelty 赢家又不同）→ **必须多轴同报**：
- **productivity**：共享预算内准入数（⚠️ 预算必须匹配——论文 300-candidate matched budget，不是无限跑）；
- **performance**：准入集平均每因子 OOS Sharpe；
- **novelty**：每因子对"自家其他 admits ∪ 面板参照集"的最大相关（平均而非 worst-case，避免单个高相关因子拖垮整体分）；
- **spanning test**（增量价值）：准入因子与参照集联合 Ridge，两 OOS 多空收益序列互相回归，报 alpha t-stat（大正值=suggestive，非 confirmatory）。
四者对应本 skill 的既有判断：单因子合格（五档单调、IR 达标）之上，**发现系统的合格 = 产出率 + 样本外绩效 + 新颖度三缺一不可**；performance 缺 novelty = 换皮重包装，novelty 缺 performance = 噪声。

### 消融启示（资源有限时的优先级）

SEADS 机制消融（论文 Table 2，Panel A）：**self-evolution 是最大承重件**——去掉后准入 7.8 vs 14.0、Sharpe 掉 68%（0.08 vs 0.25）；去掉 Planner 反而准入近 3 倍（37.2）但 Sharpe 掉——**门不严产垃圾**。→ 自己的自动化管线优先级：**严验证门 + near-pass 自进化 > 更多生成量**。

### 诚实局限（别过度解读）

准入因子每 replicate 只有几十个、OOS 窗 59~71 月 → 多数系统间差异**统计上不可区分**（论文明示）；需多 replicate（论文 5 static / 3 rolling 受 API 预算限制）与跨 replicate 标准误。

### A 股落地最小自检（三件套）

1. 候选公式只允许访问决策日可得列（沙箱/静态检查），禁 `shift(-1)`、中心化 rolling、未来日期列；
2. **每年决策日滚动重跑整条发现管线 ≥1 次**并携带状态，报告 rolling 与 single-shot 的准入数/OOS Sharpe 对比（P2）；
3. 宣传数字只出自最后一段未触碰样本，所有阈值在观察 OOS 前锁死（P3）；并在 IC 报告/因子卡上同时给 productivity/performance/novelty/spanning 四轴。

## Pitfalls

- **收益高 ≠ 好因子**：高收益常伴随高换手，成本后可能归零或巨亏
- **行业中性化是双刃剑**：降回撤但砍收益，看目标用途决定
- **五分位只尾部差异**是最隐蔽的不稳健信号，务必检查 Q2-Q4
- **decay 不是万能**：过度平滑会衰减信号本身，需平衡
