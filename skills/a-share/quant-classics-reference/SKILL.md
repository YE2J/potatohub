## 核心框架（可直接借鉴的设计模式）

### 1. 三层配置框架（时钟十）
```
战略配置(20%仓位) ← 宏观杜邦分析（产业结构长周期）
战术配置(40%仓位) ← 经济周期循环（中周期）
机动配置(0-40%仓位) ← 行业关联网络（行业热点短周期）
```
→ 与用户 L1/L2/L3 三层决策架构同构，可作架构论证引用。

### 2. 行业轮动三算法谱系（时钟九，按复杂度递进）
| 算法 | 输入 | 超额 |
|---|---|---|
| 直接动量 | 前 M 周行业收益率 | 168% |
| 半伙伴算法 | 收益率 + 行业相关系数矩阵 | **246%（最优）** |
| 伙伴算法 | 收益率 + 相关系数（热点） | 218% |

→ 结论：显式纳入**行业相关结构**比纯动量强。用户 a-share-sector-rotation 可参考半伙伴作为轮动候选。

### 3. 因子边际效用递减（国信45，因子设计铁律）
- **口径注意**：3.5%/9.8%/2.3% 是组合跑赢其全部子组合的**占比**（非增因子收益增益），且 >90% 组合增因子后反而变差——边际效用递减成立
- 静态最高累计（2005-07 起）：三 545.6% / 四 619.8% / 五 547.9%（四因子静态最优）；动态区分度调整后四 730.4%、五 758.6%
- 区分度阈值 0.05：动态打分时区分度低于阈值的因子被抑制（原文注明未做敏感性分析）
- → 与 quant-alpha-factory 的"信号数量陷阱"（相关性边际递减 0.07→0.23）互为印证

### 4. 事件冲击统计套利（43b，高频思路——需 L2/算法执行通道数据基础）
- 成本敏感性是套利策略生死线：成本 0.6%→0.2%（利息 10%→5%）后，期末收益从 3.76% 升至 177.26%，成本上升收益崩塌
- 净值<1 天数作为稳健性指标（仅 10 天）——**低水位天数**比夏普更能反映持有体验

### 5. 行业关联网络聚类（时钟八）
- 复杂网络 + 相关性 → 23 行业聚 4 集群（强周期/中周期/轻工业/…）
- 集群内轮动比行业内轮动更稳健（换仓 5.2 周一次）
- → 与用户 DC/THS 行业映射（31 申万）可交叉参考

## 使用红线

1. **参数勿直接引用**：2009-2011 实证均为当时市场事后统计，直接用于 2026 年 = 数据窥探（同 P2 教训：勿直用全窗事后统计参数）
2. 方法论可作为**假设来源**（Idea 阶段），必须用用户现有数据重新验证
3. 高频/套利类（43b/20）需要用户当前不具备的数据基础（L2/算法执行通道），仅作思路参考
4. 本 skill 只存框架摘要，全文在各 book_library 目录的 `.note.md`（report 摘要）
