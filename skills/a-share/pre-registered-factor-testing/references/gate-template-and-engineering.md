# 分层 gate 模板与面板工程技法

## 一、分层 gate 判据表（B1-B6）

| 层 | 检什么 | 典型阈值/判据 |
|:--|:--|:--|
| B1 | 覆盖度 | 有效交易日数、信号非空率 ≥ 预设（如 ≥120 个有效交易日）|
| B2 | 结构 | IC 均值、ICIR（IC 均值/IC 标准差）、分组单调性（Top-Bottom 差值符号要对）|
| B3 | 稳定 | 月度 IC 同号占比（如 ≥60%）；看跳期分布，不能只看全样本均值 |
| B4 | **kill-switch** | 控制变量分层内单调性 **<3/5 层 ⇒ 代理因子、终止** |
| B5 | 经济性 | 计交易成本 + 涨跌停/停牌不可交易后的净值 |
| B6 | 事件研究 | 信号稀疏（日覆盖 ≥1%）时的替代检验；含对照与双侧 t |

两条分支路径必须事前写死（不是跑完再选）：
- **稀疏性**：信号日覆盖率 <1% ⇒ 转连续变体（建因子时同时产出连续列，如 `div_strength`）；≥1% ⇒ 直接事件研究。
- **相关性**：|ρ(新因子, 已有常见因子)| > 0.4 ⇒ 走残差因子（对已有因子回归取残差），否则用原值。

## 二、事件研究三件套（缺一不可归档）

1. **按日截面超额**：每日分别算 顶背离/底背离/无信号 的 forward 收益，减去当日全样本均值 → 逐日超额序列 → 双侧 t 检验 + 方向胜率（超额<0 的交易日占比）。
2. **单因子对照（硬性）**：两组长短仓超额必须同时报**控制 rev_20 后的净超额**；再加 FM 回归（fwd ~ 组哑变量 + rev_20 + mom + ln_mv + 行业 FE）。
3. **方向判定按预注册原话执行**：预注册写“A 显著为负 **且** B 显著为正同时满足”，就不能因为 A 对而宣布成功。

实测校准（供判读参考）：某量仓背离信号控制 rev_20 后两组仍显著为负（t≈-7.1 / -9.6）⇒ 可排除“纯反转代理”；但底背离方向与假设相反（吸筹本应看涨却继续跑输）⇒ 假设不成立。A 股“创新低后继续跌”的下行动量效应常压倒吸筹反转逻辑。

## 三、假信号 warmup 掩码公式

```
保留该行 当且仅当：该股序列索引 i >= (最长窗 + 最短极值窗 - 1)
                 AND 价格窗长度 >= 最短窗
                 AND 水平序列极值窗长度 >= 最短窗
```

- 验收断言：“数据起点后 N 个月内伪信号行数 == 0”，并报掩码前后行数变化与最早有效信号日。
- 掩码是**所有下游检验的硬前置**，不修就跑结论会被独立复核打回。

## 四、亿行级 SQLite 面板构建

- **禁用日期区间 JOIN 做时点归属**（`ON trade_date BETWEEN in_date AND out_date`）：千万行规模下退化成嵌套循环、直接超时。改为**先造“每股唯一映射”**：`ROW_NUMBER() OVER (PARTITION BY code ORDER BY in_date DESC)` 取 1 条 → 再等值 JOIN。
- **前瞻收益用窗口函数一次算完**：`LEAD(close, N) OVER (PARTITION BY code ORDER BY trade_date)` → `lead_close/close - 1`；不要逐股循环。
- **相关性别依赖 scipy**：Spearman = 两序列分别 rank 后的 Pearson，纯 pandas 三行（`a.rank().corr(b.rank())`）；省一层依赖安装。
- **交易日对齐**：自算的动量/反转列（如 `close(t-20)/close(t-60)-1`）必须显式按 `(trade_date, close)` 对齐再做抽样匹配校验（**90/90 匹配**才算口径复现）。
- **建表前先备份大表**（gzip 落 `backups/pre_<阶段>_<时间>/`）；**重算脚本支持动态扩列**（`ALTER TABLE ADD COLUMN` 探测后补列），否则加一个窗口就得推倒重来。
- **数据覆盖要实测而非推断**：`SELECT COUNT(*), MIN(date), MAX(date) FROM t`，以及逐字段 NULL 率（注意 `=0` 与 NULL 的区别——把 0 当缺失曾导致误判“数据缺几年”）。
