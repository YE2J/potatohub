## 查询语法

```python
query = '000988 大单买入量 大单卖出量 中单买入量 中单卖出量 小单买入量 小单卖出量 特大单买入量 特大单卖出量'
```

逗号分隔多只股票：
```python
query = '000988,600519 主力净流入 大单成交量 中单成交量 小单成交量'
```

## 关键注意

1. **字段名带日期后缀**：如 `大单买入量[20260626]`，日期随查询日期变化。提取时用前缀匹配 `if '大单买入量' in key`
2. **成交量单位**：实测值 ~千万量级，单位为**股**（非手）
3. **成交额单位**：实测值 ~十亿量级，单位为**元**
4. **批大小限制**：建议 ≤15 只/次，请求间隔 ≥0.3s
5. **股票代码带后缀**：返回 `.SZ`/`.SH`/`.BJ`，需 strip

## 与现有 moneyflow_daily 表的对比

| 维度 | moneyflow_daily (东方财富) | 问财 |

| 字段格式 | 标准化固定字段 | 动态中文 + 日期后缀 |

**建议**：日常资金流数据优先用问财，替代东方财富 push2his（覆盖不足+不稳定）。
