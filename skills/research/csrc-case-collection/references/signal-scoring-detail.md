# 信号评分系统详细设计

## 设计目标

从大量证监会行政处罚决定书中精准识别"江勇案级别"的高质量操纵市场详案。1000 篇 → 粗筛后 80 篇 → 精筛后 50 篇。

## 第一层：硬性一票否决

按优先级执行，任一命中直接 DROP：

| 序号 | 规则 | 检测代码 | 依据 |
|:---:|------|------|------|
| 1 | 字数 < 1500 | `len(text) < 1500` | 江勇案 5000+，尚文彦案 ~800 |
| 2 | 非操纵市场类 | `doc.type != "market_manipulation"` | 用户只要操纵市场 |
| 3 | 表格/纯数据格式 | `digit_density > 0.25 AND NOT has_narrative` | 熊剑涛等63人案 |
| 4 | 一句话带过型 | `sentence_count < 15` | 尚文彦案特征 |
| 5 | 句均字数过少 | `total_chars / sentence_count < 60` | 对话/罗列型，非叙述型 |

### 表格检测算法（三重）
```python
table_signals = {
    "html_table": "<table>" in text or "<tr>" in text,
    "markdown_table": markdown_table_lines > 10,
    "digit_density": digit_ratio > 0.25
}
# 只有数字密度高但没有叙事段落 → 判定为表格
if digit_density > 0.25 and not has_narrative:
    return DROP("纯数据罗列")
```

### 多当事人检测
- 检测标题中的 `等\d+人` 模式
- 检查每个当事人独立描述句数
- 如果 < 10 句独立描述 → DROP

## 第二层：信号加权评分

通过硬性检查后，对每个信号打分，总分 ≥ 45/80 进入 LLM 精筛。

| 排名 | 信号 | 权重 | 正则/检测方式 | 江勇案参考值 |
|:---:|------|:---:|------|------|
| 1 | 秒级时间戳 | 5.0 | `\d{1,2}:\d{2}:\d{2}` 计数 × 5 | 大量 HH:MM:SS |
| 2 | 时间戳密度 | 1.5 | 每千字 ≥ 2 个得满分 | 高密度 |
| 3 | 手法拆解 | 4.0 | 关键词："拉升"/"封单"/"撤单"/"涨停板出货"/"对倒"/"对敲" | 完整链路 |
| 4 | 申辩复核攻防 | 4.0 | 组合词："当事人"+"提出"、"申辩"+"复核"、"不予采纳" | 完整攻防 |
| 5 | 账户控制细节 | 3.5 | "实际控制的账户"/"账户组"/"配资"/"出借" | 详细描述 |
| 6 | 成交量/金额明细 | 3.0 | "成交量"/"买占比"/"万股"/"亿元"/"万元" | 逐笔明细 |
| 7 | 多日交易序列 | 3.0 | 明确日期序列 ≥ 3 天 | 4 天 |
| 8 | 结构完整性 | 1.5 | 命中 ≥ 5 个结构标志（"经查明"/"违法事实"/"处罚决定"/"申辩"/"复核"等） | 标准段落结构 |
| 9 | 字数梯度 | 1.0 | `min(len(text)/8000, 1.0) × 10` | 5000+ |

### 高价值信号组合

```
时间戳秒级 + 手法拆解 + 申辩复核    → 99% 命中江勇级别
时间戳分钟级 + 账户控制 + 多日序列  → 70% 命中
字数 5000+ 但无手法拆解             → 警惕！可能是信披案
```

## 第三层：LLM 精筛

### 智能截取策略（节省 Token）

不送全量文本，截取三段：
```
头部 500 字（当事人+案由）
  ↓ [...省略...]
中间 2000 字（从 1/4 处截取，违法事实核心）
  ↓ [...省略...]
尾部 800 字（申辩复核+处罚决定）
────────────────────────
≈ 3300 字 ≈ 1200 tokens
```

### 精筛 Prompt

```
你是证监会行政处罚决定书质量评审专家。
目标案例：江勇操纵"天山生物"案（〔2021〕76号，~5000字）
特征：秒级时间线、具体交易手法拆解、多日序列、账户控制细节、完整申辩复核。

请对以下决定书评级（只输出 JSON，无其他文字）：

{
  "score": 0-100,
  "level": "A|B|C|D",
  "features": {
    "has_timeline": true/false,
    "timeline_granularity": "none|day|minute|second",
    "has_method_decomposition": true/false,
    "method_detail_score": 0-5,
    "has_account_control": true/false,
    "account_detail_score": 0-5,
    "has_defense_review": true/false,
    "defense_detail_score": 0-5,
    "trading_days_count": int,
    "word_count_quality": "rich|adequate|thin|bare"
  },
  "type_check": "market_manipulation|other",
  "verdict": "keep|drop"
}

一票否决：表格罗列/一句话带过/非操纵市场 → score=0, verdict=drop
```

### Token 预算

| 项 | Token |
|:---|:---:|
| 固定 Prompt | ~350 |
| 文本预览 | ~1200 |
| LLM 输出 | ~200 |
| **合计** | **~1750** |

## 违法类型自动分类

使用关键词指纹法。标题关键词权重 ×3，正文 ×1。

```python
CLASSIFICATION_RULES = {
    "market_manipulation": ["实际控制的账户", "对倒", "对敲", "封单", "撤单",
                            "涨停板出货", "虚假申报", "操纵", "连续买卖",
                            "拉抬", "打压", "集中资金优势"],
    "info_disclosure":     ["信息披露", "未按规定披露", "定期报告",
                            "重大遗漏", "虚假记载", "误导性陈述"],
    "insider_trading":     ["内幕信息知情人", "非法获取内幕信息",
                            "建议他人买卖", "内幕信息敏感期"],
}
```

分类修正规则：如果初步判定为操纵市场但操纵类关键词命中 < 3 个 → 退回第二高分类型。

## 边缘案例处理

| 场景 | 处理 |
|------|------|
| 字数达标但内容是表格 | 三重表格检测 → DROP |
| "张三等5人"多当事人 | 独立描述句 < 10 → DROP |
| 申辩复核缺失但其他信号极强 | 降权（通过线从45降至40），有些案件当事人放弃申辩 |
| "操纵财务数据"误判为操纵市场 | 上下文检测，区分"操纵股价" vs "操纵财务" |

## 效率预估

| 阶段 | 输入 | 输出 | Token |
|------|:---:|:---:|:---:|
| 类型分类 | 1000 | 400 | 0 |
| 硬性排除 | 400 | 280 | 0 |
| 信号评分 | 280 | 80 | 0 |
| 边缘处理 | 80 | 70 | 0 |
| LLM 精筛 | 70 | 50 | ~87,500 |
| **总计** | **1000** | **50** | **~87,500** |

对比全量 LLM（1000篇 × 5000t = 5,000,000 tokens）：**节省 96.5%**
