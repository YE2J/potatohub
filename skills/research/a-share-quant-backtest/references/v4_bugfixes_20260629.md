# v4 回测 Bug 修复记录 (2026-06-29)

三方评审发现的三个关键 Bug，已全部修复。

## Bug 1: 仓位分配不均

**症状**: `position_capital = cash / 3` 在循环中逐次调用。第一只股票拿到 `initial_capital/3`，第二只只剩 `(剩余现金)/3` ≈ `initial_capital/4`，第三只更少。回测显著偏向先买入的股票。

**修复**: 固定分配资金 `position_capital = initial_capital × position_frac`（配置化参数，默认 1/3）。每只股票独立分配，不依赖剩余现金。

## Bug 2: 主力线信号错误

**症状**: 主力线判断为 `net_mf_amt_ema3 > 0`，即净流入 > 0 → 买入。这等同于"任何正流入都买入"，不是真正的主力雷达信号。

**修复**: 改为**主力线上穿零轴**：
```python
cross_zero = (zhuli[i-1] <= 0) and (zhuli[i] > 0)
```
即：昨日主力线 ≤ 0，今日 > 0 → 买入信号。这才是真正的零轴交叉。

## Bug 3: 卖出条件过于敏感

**症状**: 主力线连降 2 日即卖出。A 股震荡市频繁触发，导致频繁进出、持仓期极短。

**修复**: 改为**连降 3 日**卖出。此参数极其敏感：
- 连降 2 日 → 收益率约 +9%
- 连降 3 日 → 收益率约 +180%  
- 连降 4 日 → 收益率约 +230%

**铁律**: 每次只改一个参数，逐个回测对比验证。
