# 多轮修复-复盘模式

基于 2026-07-02~03 的因子工程复盘经验。

## 模式：发现问题 → 排优先级 → 修复 → 3Agent复盘 → 再修复 → 最终验证

### 步骤

1. **发现问题**：使用多Agent并行评审发现系统性问题（数据完整性/代码质量/策略影响三个维度）
2. **排优先级**：P0(严重,立即修) → P1(中等) → P2(轻微) 三级
3. **批量修复**：按优先级顺序，一个子代理处理同一Priority的所有问题
4. **3Agent复查**：修复完成后重新派遣3个Agent验证修复效果
5. **处理遗留**：Agent发现的遗留问题立即修复，修复后验证
6. **最终汇总**：更新技能+记忆

### 典型问题分类

| 维度 | 常见问题 |
|------|---------|
| 数据完整性 | 日期格式不统一、编码映射单向、amount=0、字段来源错误 |
| 代码质量 | import循环、fallback不一致、merge格式不兼容、config硬编码 |
| 策略影响 | 信号密度过高、ST排除缺失、回测高估、阈值不合理 |

### 验证指标

每次修复后对照：
- ST排除数量符合预期（A股约4%）
- 4条件命中数变化在合理范围（0-5只）
- 覆盖率日志输出正确
- 窗口动态化边界正确
