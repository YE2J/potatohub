# 外部量化工具 / 生态系统评估框架

当用户问"有什么现成的量化工具/平台/项目可用"时，按以下维度评估后再回答。

## 评估五维框架

### 1️⃣ 数据源兼容性（最重要的筛选条件）

现有系统已建立的管线（无需再做数据适配）：
- **Tushare（主力）**：daily_kline(前复权)、moneyflow_daily(THS全量)、index_daily、adj_factors
- **SQLite 本地库**：2.2GB, 20+ 表，日线/资金流/筹码/港通/板块
- **同花顺 LV2**：大单净量、暗盘资金、主力持仓、主力雷达、GS 信号

**问题**：目标工具用什么数据？
- Pandadata 系（Quantskills.ai 上大部分技能）→ 需要做数据适配，不能直接用
- WorldQuant Brain → 自己的数据平台
- Qlib → 自带数据下载，可接 Tushare/AKShare
- RD-Agent → 底层接 Qlib 数据，可适配本地数据

**结论**：如果工具绑定非 Tushare 数据源，搬运思路 > 直接使用。

### 2️⃣ 策略类型匹配

现有策略特征：
- **方向性趋势**（GS G区间 + 主力线上穿零轴）
- **量价因子为主**（OHLCV + 资金流）
- **A股全市场扫描 → 精选3只**

目标工具覆盖什么因子类型？
- 方向性 Alpha 因子 ✅ 直接相关
- 量价统计 Alpha 因子 ✅ 直接相关
- 高频/Tick 因子 ❌ 不匹配
- 基本面因子（PE/PB/ROE）⚠️ 辅助参考
- 机器学习因子 ⚠️ 可借鉴但需改造

### 3️⃣ 社区成熟度

| 门槛 | 用于判断 |
|------|---------|
| ⭐≥500 | 有一定社区基础 |
| ⭐≥5,000 | 被广泛验证 |
| 更新时间 ≤1月 | 项目仍活跃 |
| issue 有回复 | 维护者在场 |
| 中文文档 | A股量化必需 |

### 4️⃣ 输出格式 / 接口形式

- **Python 库**（pip install）→ 最易集成
- **Agent Skill**（Quantskills/OpenClaw）→ 需要 Agent 环境
- **CLI 工具** → 可 script 化
- **独立平台** → 需切换工作流
- **论文/思路** → 只借鉴方法论

### 5️⃣ 与现有系统的集成成本

| 集成成本 | 判断标准 |
|---------|---------|
| 低 | 纯新增模块，无冲突 |
| 中 | 需要做数据适配层 |
| 高 | 需要重写策略引擎/数据管线 |

## 2026-07 发现的关键结论

1. **"500⭐+ 最近更新"在因子工具赛道非常苛刻**。因子库/策略复现项目通常一次性发布后不频繁更新。Qlib 45k⭐ 也是 2 个月前才更新。

2. **近期活跃方向是 LLM+因子挖掘**（不是传统因子库）：
   - **微软 RD-Agent**（13.7k⭐, 2026-06 活跃）— 自动因子挖掘+模型优化
   - **QuantaAlpha**（1.2k⭐, 2026-06 活跃）— LLM 自进化因子挖掘
   - 这些和 QuantsSkills 上 FactorMAD 辩论式因子挖掘思路同源

3. **数据源绑定是最大阻碍**。QuantsSkills 大部分技能绑定 Pandadata，无法直接接入 Tushare 管线。搬运方法论比搬运代码更实用。

4. **因子评估方法论（IC/分层回测/衰减）** 是第三方工具最有价值的输出，比因子本身更值得参考。
