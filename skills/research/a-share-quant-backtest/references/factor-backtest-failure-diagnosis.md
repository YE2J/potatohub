# 因子合成回测失败诊断（IC>0 但组合亏损）

> 来源：2026-08-21 P2 全流程实战（v1 四因子门控 0/6 → v2 精简三因子 1/6 → 终判风格 Beta 依赖）。
> 适用：多因子合成回测出现"合成 IC 为正但组合扣费超额大幅为负"时的标准诊断序列。

## 一、诊断决策树（按序执行）

1. **证伪"因子方向反了"** — IC 为正即数学上排除（方向反则 IC 为负）。P2 合成 IC +6.2% 但 Top10 组合最差。
2. **成本对照**（同权重，cost=0 vs 满成本）— P2：0 成本 2/6 → 满成本 1/6。成本是首因但非唯一因。
3. **十分位单调性先验** — 训练窗 composite 切十分位，看 Q1→Q10 fwd 收益：
   - v1 缺此步：Q10 跑输 Q8-9，"选最顶"≠最优，Top10 组合最差。
   - v2 修复后：秩相关 0.03→0.87 单调性修复成功，但绝对价差仅 ~0.76pp/5d → **单调性不是病根，绝对价差太小才是**（成本吞噬后无剩余）。
   - 映射：non_monotonic_tail → 避免纯 Top10，选 Top20/30 覆盖 Q8-9。
4. **双子窗分裂检验（风格 Beta 诊断）** — 训练窗切两段（例 2020-21 / 2022-23），候选规则分别评估：
   - 子窗 1 全负、子窗 2 全正 → 超额来自风格周期（小盘/价值 beta），非跨周期 Alpha。
   - P2 v2 实测：子窗 1 全部 TopN -6.8%~-15.9%，子窗 2 全部 +10.8%~+25.9% → 判"小盘熊市 beta 伪装成 Alpha"。
   - 配套：maximin 选规则 = 两子窗较差者最大（防过拟合单段行情）。
5. **多空分离** — Top10 vs Bottom10 价差来自哪一端？P2：多头 +0.11%/5d vs 空头 -1.63%/5d → 价差靠空头，纯多 Alpha 薄。
6. **单因子测试窗诊断** — 各因子独立 IC/ICIR，找唯一存活因子（P2：rev_20 IC +6.6%/ICIR 0.385）。
7. **简化因子对照** — 去弱/失效因子（P2：去 Mom/NF_5D 后训练窗超额 -7.2% → -2.25%，少亏 5pp）→ 实证支撑因子精简。
8. **排除环境嫌疑**（归因阶段一票否决）：市值风格暴露 × 基准错配（小盘反转 vs 沪深300，P2 确认非主因）；退市毒尾（fwd 缺失按现金 0 处理）；除权污染（rev_20 手算 vs 库 Spearman=1.0 已闭合）。
9. **终判** — 双子窗分裂 + 价差靠空头 + 简化后仍净亏 → "无稳定截面 Alpha"。停止调参（再调 = data snooping），交用户决策：重构 / 降频 / 多空 / 暂停 / 换赛道。

## 二、工程陷阱（实踩）

1. **"脚本写好但从未执行"** 是全会话最大元凶（p2_backtest / p2_attribution / p2_factor_diag / p2_cost_sensitivity / p2_prod_smoke 均出现"写了以为跑了"）。铁律：写 → `py_compile` → `--smoke` → 全量 → **独立验证**（SQL 断言 / grep 实查）。
2. **跨压缩边界 patch 静默失败**：patch 报 success 但文件未变 — 关键 patch 后必 grep 实查目标行。
3. **patch 副作用**：删函数定义漏删调用 → NameError；patch 误吞函数签名 → 孤儿函数体。修完必跑全链路 smoke。
4. **参考模型无工具权，其"已执行/已写文件"自述可伪造**（minimax 自称已跑归因/已写报告，实查文件不存在）— 一切以自己实跑为准。
5. **argparse 空格参数**：`--cost 0.003` 在 shell 展开时拆参 → unrecognized arguments。用 `--cost=0.003` 或引号包裹。
6. **f-string 嵌套**：Python <3.12 内部 f-string 不能用同引号 → 先算出变量再嵌入。
7. **pd.qcut 空桶/NaN**：`duplicates='drop'` + 先 dropna。
8. **量纲断言过严误拦**：比值∈[0.5,2] 拦截 10×（千元/万元），但秩相关 median=1.0 证明可用 → 以秩相关判可用性，比值仅提示。
9. **"completed 但数据为空"**：NF_5D 回填曾 2020-2022=0 行却标 completed。回填/修改类任务必须独立 SQL 分年断言，不信脚本 exit code。

## 三、重构代码骨架（p2_refactor.py 四阶段模式）

多因子重构标准流程（全部决策在训练窗内完成，测试窗只验证一次）：

1. **v2 权重**：候选因子训练窗逐日 Spearman IC → ICIR 加权归一化。**负向因子先取反再算 IC**（`rank(ascending=False)`），否则负 ICIR 被 MIN_ICIR 阈值过滤 → 因子静默消失（三因子变两因子）。权重仅内存，不覆盖线上旧版。
2. **十分位先验**：单调性 rank 相关 + shape 判定 → 映射 TopN 档位（见决策树 3）。
3. **候选规则集评估**：TopN 候选 × 训练窗双子窗 → maximin 选中。
4. **测试窗唯一验证**：6 门控（扣费超额>0 / 胜率>55% / 盈亏比>1.5 / 最大回撤<15% / 合成ICIR≥0.3 / 年化超额>5%）。成本模型：佣金万2.5双向 + 印花税千1卖出 + 滑点万5单边（满换手≈0.25%/期）。
