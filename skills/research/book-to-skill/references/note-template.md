# 学习笔记模板（步骤 6a）

> 用途：用户确认学习后，生成 `<书名>.note.md` 存入 `~/book_library/<书名>/`。
> 定位：给用户看的理解存档——是「学懂了什么」的记录，不是全文摘要。
> 原则：用自己的话重述关键概念，标记疑难点，链接到可复用 skill（若生成）。

## 模板结构

```markdown
# 《书名》学习笔记

> 作者： | 学习日期： | 来源：Z-Library (z-lib.li) | 笔记版本：

## 1. 一句话总结
（本书核心思想，30 字以内）

## 2. 关键概念（按重要性排序）
### 概念 A
- 定义/公式：
- 我的理解（用自己的话）：
- 应用场景：

### 概念 B
- ...

## 3. 核心方法/流程（可操作步骤）
1. 步骤一：...
2. 步骤二：...
（若书中给出现成流程，直接结构化列出）

## 4. 公式/规则速查
| 名称 | 公式/规则 | 适用条件 | 备注 |
|---|---|---|---|
| | | | |

## 5. 与我的知识体系的联系
- 与量化/高数已有知识的关联：
- 可应用到现有系统的点（如：可以接入 L1/L2/L3 架构的哪个环节）：

## 6. 疑难点（待解决）
- [ ] 疑问 1
- [ ] 疑问 2

## 7. 行动项
- [ ] 用书中的方法做一次练习/回测
- [ ] （若提炼了 skill）复用该 skill 验证
```

## 生成后动作

1. 写入 `~/book_library/<书名>/<书名>.note.md`
2. 更新 INDEX.md 状态列：`待学习` → `学习中`（开始读）或 `已学习`（读完）
3. 若同时提炼了领域 skill → 在笔记「7. 行动项」中引用该 skill 名
