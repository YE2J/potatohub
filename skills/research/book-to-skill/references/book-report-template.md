# 书本汇报模板（步骤 5）

> 用途：下载+转换+入库后，向用户汇报，供其决策是否学习。
> 原则：只读大纲 + 抽样关键章节，不整本读入上下文（省 token 纪律）。

## 汇报结构

### 📖 书本信息

| 项 | 值 |
|---|---|
| 书名 | |
| 作者 | |
| 年份/语言 | |
| 格式/大小 | |
| 下载来源 | Z-Library (z-lib.li) |
| 库目录 | `~/book_library/<书名>/` |

### 目录大纲

从 `<书名>.md` 提取章节结构（`grep -E "^#{1,3} "`），列出主要章节：
- 第 1 章：...
- 第 2 章：...
- ...（只列标题层级，不展开内容）

### 核心要点（3-6 条）

从抽样阅读中提炼本书最值得学的知识点：
1. ...
2. ...
3. ...

### 难度/相关性评估

| 维度 | 评估 |
|---|---|
| 难度 | 入门 / 进阶 / 专家（+依据：前置知识要求） |
| 与量化相关性 | 高 / 中 / 低（+说明） |
| 与高数学习相关性 | 高 / 中 / 低（+说明） |
| 预估学习时间 | X 小时 |
| 建议 | 值得学 / 可选 / 不值得 |

## 结尾询问（等用户决策）

> 是否学习这本书？
> - 「学」→ 生成学习笔记（note-template）
> - 「提炼」→ 生成领域操作 skill（skill-extraction-guide）
> - 「都要」→ 两者都做
> - 「不学」→ 归档保留，INDEX 状态标「暂不学习」
