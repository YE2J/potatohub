# 数学内容验证速查（等价无穷小 / 泰勒展开）

来源：2026-08-11 高数公式总结 docx 复核 + 网上资料筛选实测。用于「三档复核·档1 可数学验算」和「推荐网上数学资料前逐条验算」。

## 1. 已验证正确的核心公式表（x→0）

### 基础等价无穷小（一阶）
- `sin x ~ tan x ~ arcsin x ~ arctan x ~ x`
- `ln(1+x) ~ x`；`e^x - 1 ~ x`；`a^x - 1 ~ x·ln a`
- `1 - cos x ~ x²/2`；`(1+x)^α - 1 ~ αx`

### 差函数等价无穷小（系数极易混，重点核对）
| 差函数 | 系数 | 来源阶数 |
|---|---|---|
| `x - sin x ~ x³/6` | 1/6 | sin 展开 x - x³/6 |
| `arcsin x - x ~ x³/6` | 1/6 | arcsin 展开 x + x³/6 |
| `tan x - x ~ x³/3` | 1/3 | tan 展开 x + x³/3 |
| `x - arctan x ~ x³/3` | 1/3 | arctan 展开 x - x³/3 |
| `tan x - sin x ~ x³/2` | 1/2 | sin(1-cos)/cos |
| `x - ln(1+x) ~ x²/2` | 1/2（二阶）| ln 展开 x - x²/2 |
| `e^x - 1 - x ~ x²/2` | 1/2（二阶）| e^x 展开 x + x²/2 |
| `x - arcsin x ~ -x³/6` | 负号 | arcsin > x，左向为负 |

记忆口诀（DeepSeek 版，已验证）：**ln 与 e^x-1 基准都是 x，二阶一负一正**：
`ln(1+x) = x - x²/2 + o(x²)`，`e^x - 1 = x + x²/2 + o(x²)`。
使用铁律：乘除 → 都换 x；加减 → 展开到二阶看符号，**绝不互换**。

### 常用泰勒展开（全部验算无误，9 条）
```
sin x   = x - x³/3! + o(x³)
cos x   = 1 - x²/2! + x⁴/4! + o(x⁴)
arcsin x= x + x³/3! + o(x³)
tan x   = x + x³/3 + o(x³)
arctan x= x - x³/3 + o(x³)
ln(1+x) = x - x²/2 + x³/3 + o(x³)
e^x     = 1 + x + x²/2! + x³/3! + o(x³)
(1+x)^α = 1 + αx + α(α-1)/2! x² + o(x²)
1/(1-x) = 1 + x + x² + x³ + o(x³)
```

## 2. 验算要点（防错）

1. **交叉项必验**：两展开相乘时逐项算系数（例：`ln(1+x)/e^x` 三阶展开
   = `x - 3/2x² + 4/3x³`，x² 系数 = -1/2 - 1 = -3/2；x³ 系数 = 1/3+1/2+1/2 = 4/3）。
2. **复合函数展开**：`ln(1+x-x²)` 展开时 `(x-x²)²` 只取 `x² + o(x²)`，结果 `x - 3/2x² + o(x²)`。
3. **等价传递 ≠ 记忆等同**：`ln(1+x) ~ e^x - 1` 数学成立（都 ~ x），但
   **不建议作为记忆点**——加减法互换必踩坑（例：`[ln(1+x)-(e^x-1)]/x² = -1`，
   互换会得 0）。文档纠错时补上标（链条上下文）仍可写 `e^x - 1`，但教学建议
   独立记两个公式。
4. **小 o 运算**：`o(x)±o(x²)=o(x)`；`o(狗^α)±o(狗^β)=o(狗^α)`（β>α>0）；
   用了等价后极限为 0 大概率错（精度不够），需展开到更高阶。
