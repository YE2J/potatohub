## 4维度审查

### 1. UZI-Skill (⭐5,004)
- **功能匹配度**：★★★★ 180条量化规则 × 游资维度，与用户"买卖点"需求有重叠
- **技术栈兼容性**：★★★★★ Python，纯规则引擎
- **借鉴点**：规则品类设计思路、游资分析逻辑（龙虎榜席位）、22维数据分类
- **建议**：⚠️ 不安装，源码阅读后选择性移植规则到 strategy_library

### 2. aiagents-stock (⭐1,607)
- **功能匹配度**：★★★★ 多agent协作+LLM分析+龙虎榜+板块轮动
- **技术栈兼容性**：★★★★★ Python，LLM编排
- **借鉴点**：agent协作架构、龙虎榜分析逻辑、板块轮动预警、NL解读层
- **建议**：⚠️ 选择性实验，架构思路比代码本身价值更高

### 3. tickflow-stock-panel (⭐1,408)
- **功能匹配度**：★ TypeScript 技术栈直接致命
- **技术栈兼容性**：☆☆☆☆☆ 不兼容（TypeScript）
- **借鉴点**：LLM+策略定制交互模式的设计理念
- **建议**：❌ 跳过

### 4. KHunter (⭐305)
- **功能匹配度**：★★★ 全流程但浅层，侧重完整系统非深度因子
- **技术栈兼容性**：★★★★ Python
- **借鉴点**：风控模块（回撤/止损/仓位管理）
- **建议**：⚠️ 源码阅读风控部分，不安装全量

## 关键决策原则（可复用）

1. **"借源码"≠"安依赖"**：高价值项目可以只读源码、选择性移植，不引入运行时依赖
2. **技术栈不兼容直接跳过**：TypeScript/Java/C++ 项目只看设计理念，不做代码级审查
3. **网络不可达时更保守**：不推荐安装任何未读源码的项目，但借鉴价值仍可评估
4. **先问"用户有什么、缺什么"**：每个项目的借鉴点来自用户现有系统的缺口
