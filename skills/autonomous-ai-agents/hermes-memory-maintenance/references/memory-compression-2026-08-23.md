## 踩坑 1：memory 批量 all-or-nothing

- 症状：一次提交 10 条 operations，报错 `Operation 6: no entry matched '评估第三方工具: 查重→重复不装'`，**整批回滚零条生效**
- 根因：old_text 拼写与原文差一字（原文是"查重复"，我写"查重"）
- 教训：old_text 必须与原文完全一致；失败时从报错返回的 `current_entries` 核对原文再重发

## 踩坑 2：压缩为指针导致指针悬空

- 症状：#5"代码评审5维校验详见skill review-driven-execution"——但 grep skill 目录发现里面**没有**5维校验定义
- 根因：压缩时假设 skill 含细节，未验证
- 修复（用户选方案A）：把 5 维校验完整定义补进 `review-driven-execution/SKILL.md`（第141行起，表格+执行纪律），长期生效
- 教训：压缩到"详见skill X"前必须 `grep` 验证 skill 真实包含该细节；否则从备份恢复或补 skill
