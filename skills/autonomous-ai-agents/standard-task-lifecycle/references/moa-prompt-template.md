# MOA 建议提示词模板（Stage 1 → Stage 2 转化产物）

> 用途：Stage 1 需求确认（门禁1）通过后，Hermes 按此模板从 `requirement.md` 字段映射填充，输出可直接复制粘贴的 `/moa` 指令块。

## 字段映射规则

| requirement.md 字段 | 填入 MOA 指令块的字段 |
|:--|:--|
| 任务-名称 | `/moa 评审：` 后的一句话任务 |
| 目标（用户原话/意图） | `背景：` 段落（自包含、不依赖本对话） |
| 范围与约束 | `背景：` 段落补充（不做什么/边界/依赖） |
| 验收标准 | `请评估：` 中的评审问题（转为可评估项） |
| — | `输出要求：` 固定格式（见下） |

## 输出格式（代码块，一键复制）

````markdown
【MOA 指令】复制以下内容到对话框执行：
/moa 评审：<一句话任务>
背景：<目标 + 范围与约束 + 依赖，自包含、不依赖本对话>
请评估：<验收标准转为评审问题，逐条列出>
输出要求：按 🔴P0 / 🟡P1 / 🟢P2 分级列出，每项给证据与修复建议，最后给"是否可合入/是否可行"结论
````

## 使用注意

- **预填内容**：Hermes 从 requirement.md 自动提取填充，用户可直接粘贴；用户也可自行修改后执行。
- **门禁2 铁律不变**：无用户粘贴的 MOA 输出 = 无结果，门禁2 永不通过（见 SKILL Incident Registry Case #1）。
- 原始 MOA 输出落盘任务目录 `moa_raw/` 后再聚合汇报。
