# 问财 OpenAPI — 股票数据查询模板

> 首选数据源。2-3 次 API 调用覆盖行情、行业、三张财务报表的全部需求。
> 比之前拼凑东方财富 push2/搜狐/curl 的方案减少 80%+ 调用量，零失败。

## 前提

- `IWENCAI_API_KEY` 已配置（shell profile + Hermes env）
- 端点：`POST https://openapi.iwencai.com/v1/query2data`
- 认证头：`Authorization: Bearer <KEY>`
- 完整调用规范见 `iwencai-skillhub` 技能的 `references/hithink-openapi.md`

## 查询模板

### 1. 行情+估值（hithink-market-query）

```python
query = "600519,000001,600276,300750,002415 最新价 涨跌幅 PE_TTM PB 总市值 换手率"
```

返回字段（中文 key）：
- `最新价` — 收盘价
- `最新涨跌幅` — 涨跌幅（小数）
- `最新市盈率ttm` — PE(TTM)
- `最新市净率` — PB
- `总市值[YYYYMMDD]` — 总市值（元）
- `换手率[YYYYMMDD]` — 换手率
- `开盘价_前复权[YYYYMMDD]` / `最高价_前复权[YYYYMMDD]` / `最低价_前复权[YYYYMMDD]`
- `成交量[YYYYMMDD]` / `成交额[YYYYMMDD]`

### 2. 行业分类（hithink-finance-query）

```python
query = "600519,000001,600276,300750,002415 所属行业 申万一级行业"
```

返回字段：
- `所属同花顺行业` — 三级数组 `["一级","二级","三级"]`
- `所属申万一级行业` — 申万一级行业名称

### 3. 三张财务报表（hithink-finance-query）

**资产负债表：**
```python
query = "600519,000001,600276,300750,002415 2025年度 资产负债表 总资产 总负债 归属母公司股东权益"
```

返回字段：`总资产[20251231]`、`负债[20251231]`（注：key 是"负债"不是"总负债"）、`归母权益[20251231]`

**利润表：**
```python
query = "600519,000001,600276,300750,002415 2025年度 利润表 营业总收入 营业利润 归属母公司净利润"
```

返回字段：`营业总收入[20251231]`、`营业利润[20251231]`、`归母净利润[20251231]`

**现金流量表：**
```python
query = "600519,000001,600276,300750,002415 2025年度 现金流量表 经营活动产生的现金流量净额"
```

返回字段：`经营活动产生的现金流量净额[20251231]`

## 关键注意事项

1. **字段名是中文**：不是英文 key，取值需要用 `item["最新市盈率ttm"]` 而非 `item["pe_ttm"]`
2. **日期后缀**：时间序列字段带 `[YYYYMMDD]` 后缀，如 `总市值[20260616]`
3. **同花顺行业是数组**：`["医药生物","化学制药","化学制剂"]`，索引 0 是一级行业
4. **多股票批量**：逗号分隔股票代码即可，一次查询覆盖全量，无需循环
5. **响应格式**：`{"datas": [...], "code_count": N, "columns": [...]}` — 先看 columns 确认实际字段名再取值
6. **股票代码带后缀**：API 返回 `600519.SH` / `000001.SZ`，使用前需 `replace('.SZ','').replace('.SH','')` 剥离
7. **成交量单位是股**：`成交量[20260617]` 返回股数（如 4480330），写 daily_kline 需 `/100` 转手（44803）

## OHLCV 批量拉取

```python
query = "600519,000988,301338,000001 开盘价 最高价 最低价 收盘价 成交量"
```

返回字段（均带 `[YYYYMMDD]` 后缀）：
- `开盘价[20260617]`, `最高价[20260617]`, `最低价[20260617]`
- `收盘价[20260617]`, `成交量[20260617]`（⚠️ 股，非手）

写入 SQLite 模板：
```sql
INSERT OR REPLACE INTO daily_kline (stock_code, date, open, high, low, close, volume)
VALUES (?, ?, ?, ?, ?, ?, ?)
-- volume = api_volume / 100.0
```

## 估值模型映射（申万一级行业）

```python
MODEL_MAP = {
    "银行":     "PB + DDM",
    "食品饮料":  "PE + PEG",
    "医药生物":  "DCF + PE",
    "电力设备":  "EV/EBITDA + PE",
    "电子":     "PE + PEG",
    "计算机":   "PE + PS",
}
# fallback: "PE + EV/EBITDA + PEG" (通用制造业)
```
